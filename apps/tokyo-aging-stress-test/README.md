# 東京都 高齢化ストレステスト

3つの局がバラバラに出している公式推計を同じ区市町村名で結合し、
**高齢者1人を支える昼間の働き手が何人になるか**を2045年まで出す。

> 支え手比率が 1.0 を切る自治体は、**2020年は53のうち0。2045年は12。**

いま東京のどの区市町村も、高齢者1人に対して働き手が1人以上いる。20年後、そうでない街が12できる。
そして支え手のランキングは高齢化率のランキングと一致しない
（東大和市 高齢化率35.0%・支え手0.70 が、檜原村 67.8%・0.74 と同じ帯に落ちる）。

## 使い方

```
python3 scripts/fetch_sources.py     # 公式ソース4本を取得し、形を検査する
python3 scripts/build_dataset.py     # 結合して data/stress_test.json / .csv を出す
python3 scripts/verify.py            # 受け入れ検査
```

Phase 1 の成果物は `prototype/index.html`（ダブルクリックで開く。サーバー不要）。
