# 東京の働き手は、いま入れ替わっている

3つの局がバラバラに出している公式推計を同じ区市町村名で結合し、
**65歳以上の昼間就業者がどこでどれだけ増えるか**を2045年まで出す。

> **東京で働く65歳以上は 101万人 → 135万人（+34.0%）。同じ期間、全就業者は −5.2%。
> 2045年、東京で働く人の 14.0% が65歳以上。**

全体が減る中で、高齢者の労働だけが3割増える。支えられなくなる話ではなく、担い手が入れ替わる話。
「老いを輸出資源に」の原資が、既に100万人規模で存在している。

増加数の上位は都心（中央区 +32,288 / 港区 +29,549 / 千代田区 +26,258）。
一方で**就業者に占める割合**で並べ替えると郊外が上がる。**増える場所と、頼りになる場所は違う。**

## 使い方

```
python3 scripts/fetch_sources.py     # 公式ソース4本を取得し、形を検査する
python3 scripts/build_dataset.py     # 結合して data/stress_test.json / .csv を出す

```
