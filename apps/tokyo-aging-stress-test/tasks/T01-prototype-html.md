# T01 プロトタイプ画面を1枚作る

## 決まっていること（迷わなくてよい）

- **成果物は `prototype/index.html` の1ファイルだけ。** ビルド不要・サーバー不要・外部CDNなし
- データは `data/stress_test.json` を**HTMLに直接埋め込む**。`fetch()` は file:// で失敗するので使わない
- 素の HTML + CSS + JavaScript。フレームワークを入れない

## 作るもの（この3つだけ。増やさない）

1. **見出しの数字**
   「高齢者1人を支える昼間の働き手が1人を切る街 — 2020年 0 / 2045年 12」
   53自治体中であることを添える

2. **一覧（53行）**
   列＝自治体／2045年 高齢化率／2045年 支え手比率／2045年 単独世帯率。
   既定は支え手比率の低い順。**列の見出しを押すと並べ替わること**
   （高齢化率で並べ替えると順位が入れ替わるのを見せるのが目的）

3. **1自治体を選ぶと詳細**
   2020・2025・2030・2035・2040・2045 の 高齢化率・高齢者数・昼間就業者数・支え手比率 を並べる。
   数字の表で足りる。グラフは任意

加えて画面下部に:
- 結合できなかった9自治体を理由つきで（`excluded` にある）
- 出典3本（社人研 地域別将来推計人口(令和5年推計) / 東京都就業者数の予測(令和7年) / 東京都世帯数の予測）
- 「2020年は実績値、以降は推計。2045年より先へは外挿していない」
- 「昼間就業者はその自治体で働く人で、住む人ではない」
