# まちかどQR — ここはどこ

軒先に貼ったステッカーを起点に、**いまいる場所を確定させる**。
迷った人（子ども・高齢者・外国人）が、自分の居場所を説明できなくても済むようにする。

## なにをするか

QRを読むと1画面が開く。

1. **いまいる場所の住所を特大で出し、音声で読み上げる** — ここで解決する人が一番多い
2. **110 / 119 は直接発信のボタン**。同じ画面に読み上げる住所が出ている
   （**緊急通報の経路に何も挟まない**。窓口を作らず、本人の端末から直接かける）
3. **かえりみち** — おうちの人に電話 ／ 地図を開く ／ 道をおしえて ／ 家族を登録

## 用途の優先（2026-08-23 オーナー決定）

- **主用途は迷子**（子ども・高齢者・外国人）
- 110/119 は「すぐ発信できる」だけでよい。住所が印字されていれば発信者が伝えられる
- 家に帰る方法は3つ: 登録した保護者へ発信 ／ 地図アプリを開く ／ 位置情報から道案内

## 設計で決めていること

- **入力させない。** 目的地の入力欄を作らない。打つ操作が要る時点で単独完結が崩れる
- **読んだ瞬間に喋る。** 画面を読む前に音声が出る（生きがい1位がラジオ・新聞の層に届かせる）
- **端末の外に出さない。** 家族の電話番号と自宅住所は localStorage のみ。送信しない
- **持っていない値を出さない。** 住所から緯度経度を引く手段が無いので、
  自宅を住所だけ登録した場合は方角を出さず、住所をそのまま表示する
- **遠ければ歩かせない。** 直線2km超は「歩いて帰らないでください」を出す
- **点から点へ渡す。** 自宅方向にある40〜400mの候補地を「次に読むステッカー」として出す。
  位置を推定し続けず、確定した点から確定した点へ渡る

## 使い方

```
python3 scripts/build_points.py      # 貼付候補地の台帳をつくる
python3 scripts/build_prototype.py   # 単体HTMLを生成
```

`prototype/index.html?p=<場所コード>` を開く（例 `?p=羽村0001`）。QRはこのURLを指す。

## 貼付候補地

東京都総務局「都内災害時帰宅支援ステーション協力店舗一覧（令和7年3月31日）」から
**1,242点 / 48自治体**。この店舗は既に災害時に軒先を開けると表明しており、交渉の出発点になる。

**これは貼る候補の名簿であって、実際に貼られた場所ではない。**

### 元ファイルの落とし穴（2026-08-23 実測）

1. 拡張子が `.csv` だが**中身は xlsx**。csv として開くと壊れる
2. **11,003 行あるが、実データは 1,242 行だけ**。1,243 行目以降は座標が生成値で、
   世田谷区の住所に島根の座標、千代田区の住所に中国の座標が入っている。住所の番地も
   `2-25-131` のような値になる。**件数だけ数えると 9,738 件の偽の点を配ることになる**
3. 行き先データ（だれでも東京）にも座標の誤りがある。「大江戸線 本郷三丁目」は住所が
   文京区なのに座標が葛飾区亀有だった

`build_points.py` は東京都の範囲に入らない座標を落とし、行き先は
「住所が名乗る自治体の貼付候補のうち最寄りまで 3km 以内」でなければ落とす。
落とした件数は毎回表示する。**迷った人に反対方向を示さないための門。**
