# 都民ニーズに近づけるハッカソンテーマの推奨案

作成日: 2026-08-23  
状態: **企画書反映前の推奨案**

## 1. 結論

既存候補のうち、東京都民の身近な困りごと・要望に最も近づけやすいのは、次の2候補を統合したテーマである。

- 候補4: **職住医福 到達性マップ**
- 候補5: **高齢者の暑熱・災害時の避難アクセス**

### 推奨テーマ

**高齢者・要配慮者のための、暑さと災害に強い生活圏ナビ**

### 課題設定

高齢者・要配慮者が、猛暑や災害時でも、自宅から涼しく休める場所、医療・介護施設、避難所、公共交通まで、安全で無理のない移動経路を見つけられるようにする。

「2100年の東京」という長期構想を、都民が日常生活で使える「今日の移動・避難・支援先」の課題に接続する。

## 2. 都民ニーズとの対応

都知事杯オープンデータ・ハッカソンの公式テーマページには、都民の声として以下の要望が掲載されている。

| 公式テーマ | 都民の要望 | 推奨テーマとの接続 |
| :-- | :-- | :-- |
| 防災 | 災害時における安全な避難経路の案内 | 避難所・浸水リスク・危険箇所を重ねた移動支援 |
| 気候変動 | 暑い日に涼しく安全に過ごせる場所、年齢・体調を踏まえた熱中症回避 | クールスポット・給水・休憩拠点の案内 |
| 交通・移動 | 車いす等に応じた移動ルート、コミュニティバスを含む交通案内 | バリアフリー施設・公共交通・休憩地点を含む生活動線 |
| 生活 | 介護状況に応じた施設・サービスとのマッチング | 医療・介護・福祉サービスへの到達性の可視化 |
| 福祉・地域共生 | 居場所、地域交流、支援制度・相談先の案内 | 高齢者が孤立しない生活圏の拠点案内 |
| 健康・スポーツ | 身近で無理のない健康づくり、医療への案内 | 徒歩・休憩・医療アクセスを一体で提示 |

## 3. 既存候補の位置づけ

| 候補 | 都民ニーズとの距離 | 今回の扱い |
| :-- | :-- | :-- |
| 候補5: 暑熱・災害避難アクセス | **最も近い**。防災・気候変動の要望と直接一致 | 中核機能 |
| 候補4: 職住医福 到達性マップ | 交通・生活・健康・福祉に広く接続 | 候補5に統合 |
| 候補7: 高齢就労・地域参加 | 社会参加・活躍、福祉・地域共生に近い | 将来拡張または補助レイヤー |
| 候補2: パイロット候補地スコアリング | 行政・実証側の意思決定支援であり、住民の直接課題からは一段遠い | 裏側の優先度評価に利用 |
| 候補3: データ欠損・不確実性の可視化 | 住民向け課題ではなく、説明責任・データ品質の機能 | 画面内の注記・評価レイヤー |
| 候補1: 転入ゼロ×2100東京シミュレータ | 長期構想の背景として有効だが、日常の困りごととは距離がある | 導入説明・将来シナリオに限定 |
| 候補6: 記憶・文化資源アーカイブ | 社会参加・観光には接続するが、公開データが薄い | 今回は主題にしない |

## 4. 2日間で作る最小スコープ

広域・全対象者向けの経路検索ではなく、以下に絞る。

- **一地区**: データが揃う区市町村またはモデル地区
- **一利用者像**: 高齢者、または車いす利用者などの要配慮者
- **一動線**: 自宅周辺から医療・介護・避難・休憩拠点まで
- **表示する情報**: 移動経路、公共交通、バリアフリー設備、クールスポット、給水・トイレ、医療・介護施設、避難所、浸水等のリスク
- **重要な注記**: 段差、屋根、ベンチ間隔などの詳細な線データが不足する場合は、推定せず「未整備・確認が必要」と表示する

目的は完全なナビゲーションを完成させることではなく、複数のオープンデータを組み合わせて、どの生活動線が安全・快適で、どこにデータ不足があるかを示すことである。

## 5. SILVERPUNK // 2100 との接続

高齢者を「支援されるだけの存在」ではなく、働く・学ぶ・交流する・案内する主体として位置づける構想は維持する。ただし、今回のハッカソンでは、まず高齢者が地域内を安全に移動し、医療・福祉・交流・就労の拠点へ到達できる基盤を可視化する。

将来的には、公式テーマの「社会参加・活躍」に接続して、経験・技能を活かせる地域活動、ボランティア、学び、就労機会を生活圏ナビに追加する。個人の健康情報や適性情報を使うAI求人マッチングは、公開データとプライバシーの制約が大きいため、今回の実装対象には含めない。

## 6. 判断

企画書の「今回取り組むこと」には、候補1・候補2を前面に出すより、次の一文を中心に置くのがよい。

> 高齢者・要配慮者が、猛暑や災害時でも、医療・介護・避難・休憩の拠点へ安全に到達できる生活圏を、東京都オープンデータで可視化する。

候補1の2100年シミュレーションは、なぜ今から生活圏の再設計が必要なのかを説明する背景として残す。候補2の候補地スコアリングは、どの地区から実証を始めるかを決める行政・運営側の機能として扱う。
