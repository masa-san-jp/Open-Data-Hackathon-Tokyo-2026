# SILVERPUNK // 2100 先行事例・未充足領域調査

- 調査日: 2026-08-22
- 対象: [ギャップ解消詳細要件：網羅性検証レポート](https://github.com/masa-san-jp/Open-Data-Hackathon-Tokyo-2026/blob/main/docs/planning/20260822-silverpunk2100-requirements-completeness-review.md)で整理されたG1〜G16
- 目的: 各領域の国内外の先行取組を一次情報中心に一覧化し、「すでに解かれている部分」「まだ十分でない部分」「公開情報で統合先行例を確認できない部分」を切り分ける

## 1. 結論

### 1.1 「誰も取り組んでいない領域」は、領域単位では確認できない

G1〜G16のすべてで、制度、技術、サービス、標準、研究又は都市施策の先行例を確認した。したがって、**16領域のうち、構成要素に誰も取り組んでいないと判断できる領域はない**。

一方で、SILVERPUNK // 2100が必要とするのは個別要素ではなく、就労、医療、住宅、移動、文化、権利、財政を一つの都市運営として接続することである。この統合水準で見ると、次の六領域は特に未成熟である。

1. G6 高齢化の物語・社会受容
2. G7 技能・記憶の継承
3. G8 超長期資本
4. G9 都市ブランド・知財
5. G15 公平性・分配
6. G16 行政財政・調達・運用能力

これらは取組自体がないのではない。**個別のキャンペーン、保存制度、ファンド、都市ブランド、影響評価、調達標準は存在するが、当事者の権利、利益配分、長期運営、世代間公平までを一体運用する先行例を、今回調査した公開一次情報からは確認できなかった**という意味である。

### 1.2 最も先行しているのはG11・G12、最も白地が大きいのは領域間の接続部

- G11 住環境とG12 介護・福祉は、シンガポール、日本、米国等に常設・制度化された統合モデルがある。
- G1、G2、G3、G5、G10、G13、G14、G15、G16も、制度又は基盤単体では成熟している。
- しかし、**健康状態に応じて仕事を安全に再編する仕組み、技能記録のAI利用権と報酬、75年の資本・更新計画、世代・所得別の負担便益台帳**など、複数領域をつなぐ仕組みが弱い。
- SILVERPUNK // 2100の差別化余地は、新しい単体技術よりも、**既存の先行要素を権利・責任・財政・証拠で接続する都市運営モデル**にある。

## 2. 調査方法と判定基準

### 2.1 調査範囲

- 政府、自治体、国際機関、大学・公的医療機関、公式プロジェクトの公開情報を優先した。
- 商用サービスは、公式サイトで継続運用又は導入実績を確認できるものに限定した。
- 「先行例なし」は世界中に存在しないことの証明ではない。本報告では、**今回確認した公開一次情報に、同等の統合運用例が見当たらない**ことを表す。
- 研究論文を網羅するシステマティックレビューではなく、構想上の競合・参照モデルを発見するためのスコーピング調査である。

### 2.2 成熟度

| 点 | 状態 |
|---:|---|
| 4 | 法制度化、標準化又は複数地域で本番運用されている |
| 3 | 単一地域・組織で継続運用され、実利用者がいる |
| 2 | 実証、限定導入、臨床研究又は移行途上である |
| 1 | 構想、ガイドライン、単体部品又は断片的な取組にとどまる |
| 0 | 今回の公開一次情報調査では確認できない |

「要素成熟度」は領域内の最も進んだ構成要素を、「統合度」はSILVERPUNKの要件群を一体運用している程度を表す。点数は比較のための調査者判断であり、外部認証ではない。

## 6. 競争・実装上の含意

### 6.1 新規性を主張すべき場所

「高齢者住宅」「自動運転」「長寿医療」「高齢者就労」「Age-friendly city」自体を世界初とは主張できない。新規性候補は次である。

- 健康情報を最小開示の職務制約へ変換し、本人承認で仕事とアシストを同時調整すること
- 技能・記憶の収録からAI利用、継承、報酬、撤回までを権利台帳で一貫管理すること
- 住宅・ケア・仕事・移動を負担可能性とデータ同意まで含めて同一街区で運用すること
- 75年の資本・更新・撤退設計と、世代・所得別分配評価をGo/No-Go条件にすること
- 年齢にやさしい都市ブランドを、実測証拠、当事者統治、ライセンス条件に連動させること

### 6.2 直ちに実証すべき最小統合単位

最初からG1〜G16を同時実装する必要はない。白地と実現可能性の両方が高い次の三つを優先する。

1. **健康制約適応型マイクロワーク:** 職務カード、本人同意、短時間シフト、代替要員、環境改善、アシスト機器を一つの実証にする。
2. **権利付き技能継承:** 10件程度の技能を対象に、利用目的別同意、AI利用可否、教材、後継者、報酬、削除を端から端まで実装する。
3. **一つの生活OD:** 自宅から診療・仕事・買物のいずれか一目的地まで、予約、移動、翻訳、介助、通信断時代替を完遂する。

各実証は、技術稼働率だけでなく、本人便益、断念率、事故・ヒヤリハット、属性別格差、運用者工数、1件当たり総費用を測る。

## 7. 最終判定

- **先行例が全くないG領域:** 0件
- **先行要素は成熟しているが、SILVERPUNKとして統合不足:** 16件中16件
- **特に統合白地が大きい領域:** G6、G7、G8、G9、G15、G16
- **最も参照可能な統合先行領域:** G11、G12
- **最も重要な結論:** SILVERPUNK // 2100の競争優位は要素技術の所有ではなく、既存要素間の権利、責任、分配、財政、停止条件を都市運営として実証することにある。

本報告は「誰もやっていない」と断定するための証明ではなく、公開一次情報から確認できる競争地図である。世界初等を対外表明する場合は、特許・論文・調達・企業事例を含む追加の先行技術調査と法務レビューが必要である。
