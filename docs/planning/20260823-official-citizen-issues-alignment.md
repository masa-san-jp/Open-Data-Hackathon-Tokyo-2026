# 公式「都民の声」テーマとの照合 — T1〜T9はどれが土俵に乗るか

作成日: 2026-08-23 ／ 出典: [都知事杯OD 課題ページ](https://odhackathon.metro.tokyo.lg.jp/issues/)（2026-08-22取得）

公式サイトの「暮らしの関心ごと」12カテゴリのうち関連7カテゴリのクラスター
（都民の声のまとまり・計38件確認）を読み、[具体的課題T1〜T9](../proposal/20260822-hackathon-tasks-selection.md) と照合した。

## 1. 結論

| 順位 | 課題 | 当たり方 |
| :-- | :-- | :-- |
| 🥇 | **T7 暑熱×要支援リスクレイヤ** | c05 気候変動の**4クラスター中4つ**に正面から当たる |
| 🥈 | **T5 候補業務の実在確認（高齢就労）** | c09・c07 の2カテゴリに「高齢者の経験を活かす場」の声が実在 |
| 🥉 | **T1/T2/T3 2100シミュレータ** | 直接の声はないが「長期見通しのシミュレーション」型需要（c06-4）と「影響の可視化と行動提案」（c05-3）に接続可能 |
| ⚠️ | **T9 ＋ 補助金突合資産** | c06-6「**税の使い道の見える化**」が公式テーマに実在。7月のM1資産（突合率85.7%・追えない1,284億円）が公式テーマ直撃で復活し得る |
| △ | T4 スコアリング単独 | 直接該当なし。散在する「案内・可視化」の声を**地区単位で束ねる**語り方で全体の受け皿にする |
| ✕ | T6 記憶アーカイブ | 直接該当する声なし。戦略上はP0だが、都民テーマへの寄せでは前面に出さない |

## 2. 照合の根拠（クラスター原文）

### c05 気候変動（4件表示中）→ T7・T8・T3

| 都民の声（原文） | 対応 |
| :-- | :-- |
| 暑い日でも涼しく安全に過ごせる最寄りの場所や、休憩のとり方の提案 | T7: シェルター・避難所×高齢者分布 |
| 気温・天候や年齢・体調などを踏まえたリスクの見落とし防止による、熱中症の予防・回避行動の促進 | T7: 要支援×暑熱の交差 |
| 気候変動による暮らしへの影響の可視化と適切な行動の提案 | T1/T3: 2100年ストレステスト表示 |
| 地域のみどり、クールスポットなどを可視化し、地域の暑さ対策を促進 | T8: クーリングシェルターOD実測**3件**＝欠損の証明とセットで回答 |

### c09 福祉・地域共生（5件）→ T5・T4

- 高齢者などが、自身の知識・経験を活かせる地域貢献の場の案内 ← **T5直撃**
- 単身者が孤立せず、地域活動や社会活動に参加しやすい仕組みや情報提供
- 家庭の状況や関心に応じた居場所や地域交流機会の案内／支援制度・相談先の案内／子育てネットワークの案内

### c07 社会参加・活躍（6件）→ T5

- 世代を問わず、経験・スキルを活かして活躍できる機会の案内 ← **T5直撃**
- 地域貢献・社会貢献の機会と自身の強み・適性とのマッチング
- 障害や特性があっても活躍できる機会／ボランティア案内／リスキリング／言語の壁をAIで補う

### c06 生活（6件）→ T1系・T9

- 家計データや**平均余命に基づく老後の生活設計・資金シミュレーション** ← 長期シミュレーション型需要の実在証明
- **身近な暮らしに活かされている、税の使い道の見える化** ← 補助金M1資産の受け皿
- 要介護状況に応じた施設・サービスとのマッチング／ライフイベント手続案内／住宅確保支援／支援制度案内

### c01 防災（7件）→ T7隣接

- 世帯構成などに応じて、日常の備えと災害時の行動を提案 ← 高齢単身×防災の交差
- 地域ごとの災害リスク把握・避難経路案内・被災情報の一元把握 ほか

### c11 交通・移動（5件）／ c03 健康・スポーツ（5件）

- 車椅子・ベビーカー対応ルート、コミュニティバス案内など。UAD文脈と整合するが、
  ホワイトスペース分析のとおり移動・バリアフリー系は**過去受賞が集中するレッドオーシャン**であり主戦場にしない
- 健康は「健診結果に応じた提案」等、個人データ前提が多くOD単独では立ちにくい

## 3. 見せ方への反映（提案）

**PROOF MAPの構成は変えず、デモの入口をT7に置く。**

1. 冒頭2分: 「2100年、猛暑日30日の東京。涼める場所を最も必要とする人の分布はこれ。今のODではクーリングシェルターが3件しか見えない」（c05の4クラスターへの正面回答）
2. T3: 「その未来に一番早く着く街はここ」（可視化→行動提案の型）
3. T4/T9: 地区選定とパイロットカード（c09/c07の高齢者活躍の声を裏書きに）

補助金M1資産（[実測](../concept-research/)・`wip/readme-hojokin-framing` ブランチ）の
T9への組み込みは工数次第のオプションとし、採否はオーナー判断。

## 4. 限界

- クラスター一覧はカテゴリページの表示テキストのみで、各クラスターの詳細ページ・元となった都民意見の件数分布までは未取得
- 「都民の皆様から寄せられたご意見等を踏まえ」とあるが、集計方法は非公開
- 照合はタイトル文言ベースであり、審査で同じ重みづけがされる保証はない
