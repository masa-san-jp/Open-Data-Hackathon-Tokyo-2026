# living-zone-navi — 実装タスクキュー

このディレクトリは、[`../AGENT.md`](../AGENT.md) に従ってエージェントが自律実装するためのタスクキューである。

## 実行ルール

1. `AGENT.md`、設計仕様書、実装計画書を読む。
2. 依存タスクが完了している `status: todo` の最小番号を取得する。
3. タスクの `status` を `doing` に変更してから実装する。
4. タスクに記載されたファイル以外を変更しない。
5. `fetch → build → verify → ブラウザ目視` を実行し、タスク末尾に証跡を書く。
6. 完了条件を満たしたら `status: done`、外部状態が必要で進められなければ `status: blocked` にする。

## 最短デモ経路

```text
T01 → T02
```

T01でブラウザ起動可能な骨組み、T02でD1〜D5の集計と欠損パネルを成立させる。D6の町丁位置参照、距離計算、2100年トグル、印刷カードは後続フェーズであり、最初のデモをブロックしない。
