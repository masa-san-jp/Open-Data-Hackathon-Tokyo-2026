# 実装計画 — 暑さと災害に強い生活圏ナビ

作成日: 2026-08-23 ／ 前提: 本番2日目・残り実働 ~6h ＋ 収録期間(8/26-30)での磨き込み

## 1. 原則

- **各フェーズの終わりで必ずデモできる**（main は常に `prototype/index.html` が開ける）
- フェーズは直列。前のフェーズを壊す変更をしない
- 遅れたら機能を削るのではなく**フェーズごと切り捨てる**（Phase 2/3 が無くても作品として成立する設計）

## 2. フェーズ分割と時間配分

| Phase | 名前 | 中身 | 目安 | 対応タスク |
| :-- | :-- | :-- | :-- | :-- |
| **0** | **数字が出る** | 骨組み＋D1〜D5取得＋施設/人口の集計HTML（地図なし・表とヘッダ数字のみ） | **90分** | T01, T02 |
| **1** | **地図で見える** | D6結合→距離→reach判定→SVG地図＋ワースト表＋欠損パネル | 3h | T03, T04 |
| 2 | 2100に耐えるか | 高齢者係数トグル（ストレステスト表示） | 1h | T05 |
| 3 | 次の一歩 | パイロットカード（印刷1枚: 選定町丁・欠損一覧・次の30日） | 1h | T06 |

**デモの最低ライン = Phase 0。** ヘッダ数字（「涼み処ODが未公開＝判定不能」を含む）だけで主張は立つ。
