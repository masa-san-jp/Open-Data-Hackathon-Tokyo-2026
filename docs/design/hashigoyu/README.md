# はしごゆ — 終了記録

状態: 終了（2026-10-04）

東京都知事杯でファイナリストに選出されなかったことを受け、プロジェクトを終了する。設計・実装・デモの成果をリポジトリに保存し、今後の開発・実運用への移行は行わない。

## 到達点

- P0の静的デモとP1のReactプロトタイプを完成。
- 入浴者向け「はしごゆ」、銭湯向け「番台」、管理者向け「管理」の3画面を実装。
- 予算から1日の必要客数を計算し、来客数の不足とルート提案へ連動する仕組みを実装。
- SQLiteスキーマとHono APIサーバーの雛形・ヘルスチェックを実装（最新mainの記録による）。
- 現金目標を含む必要客数計画、銭湯基本情報の管理、スマホ・タブレット対応、デザイン刷新を実施。
- 2026-08-27にCloudflareで3画面の公開と旧URLのリダイレクトを確認（実装計画の記録による）。

## 終了時の制約と未完了事項

銭湯名・住所・人数・金額は架空のサンプル。データはインメモリで、実運用のシステムには至っていない。

SQLiteを使った永続化処理、業務API、実データ投入、休業日管理、ロール認証、QR／POS連携、月次出力、監査・バックアップ・監視は未実装。運営主体、データ取得元、連携先などの未決事項は解決せず、終了時点の記録として残す。
