# SILVERPUNK PROOF MAP — 実装タスク

このディレクトリは、実装エージェントが上から順に自律実行するためのタスクキューである。

## 実行ルール

1. [`../AGENT.md`](../AGENT.md) と設計仕様書・実装計画書を読む。
2. `status: ready` かつ依存タスクが完了している最小 ID のタスクを1つ取得する。
3. タスクファイルの `status` を `doing` に変更し、担当ファイルを確認する。
4. 担当ファイルだけを変更し、受け入れ条件を実行する。
5. `evidence/run-log.md` に実行コマンドと観測結果を追記する。
6. タスクファイルを `done` または `blocked` に更新し、変更・検査・残課題を追記する。

## 状態

```text
ready → doing → verifying → done
                   └──────→ blocked
```

`blocked` は、代替案を試しても外部状態または未決定事項のために推測なしで進められない場合だけ使う。地図、実データ取得、高度なスコアが止まっても、Phase 1 の fixture と静的画面へ縮小して進める。

## 最短デモ経路

```text
T00 → T01 → T02 → T03 → T06
```

この経路だけで、3地区の比較、地区詳細、根拠・欠損、30日アクションを表示するオフラインデモを成立させる。T04・T05・T07・T08 は、デモを止めずに並行または後続で実施する。
