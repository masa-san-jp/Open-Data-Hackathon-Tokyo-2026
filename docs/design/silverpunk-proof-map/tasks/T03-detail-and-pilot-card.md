# T03 地区詳細と30日パイロットカードを作る

## 目的

「見える化」で終わらず、選択地区の次の検証行動へ接続する。

## やること

- 地区を選ぶと詳細パネルが開く
- 指標、単位、対象年、データ状態、計算式を表示する
- 確認済みの拠点カテゴリと、未確認・比較不可の項目を分ける
- 次の固定構造を持つカードを表示する
  - 仮説
  - 30日アクション最大3件
  - 測定指標
  - 中止条件
  - 次の判断
- 「経路の安全を保証しない」「緊急時は公式情報を確認」の注意書きを入れる

## 完了条件

- 1地区のカードを開いて閉じられる
- 30日アクションがデータ状態を無視して断定していない
- キーボード操作で地区選択と詳細開閉ができる
- run log にブラウザで見た結果を追記する
