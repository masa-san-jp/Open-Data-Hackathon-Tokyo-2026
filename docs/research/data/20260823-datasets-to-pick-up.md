# 拾っておくデータ一覧（検証状態つき）

作成: 2026-08-23 ／ 作成者: hisyo ／ 本番2日目の朝時点

複数のエージェントと人が並行で触るため、**「実際に開いて中身を確認したもの」と「URLだけ確認したもの」を
行単位で分けてある**。未検証の行を検証済みとして引用しない。中を開いたら、この表の状態欄を更新すること。

## A. 検証済み — 中身を開いて粒度を確認したもの

### A-1. 社人研 日本の地域別将来推計人口（令和5年推計）東京都

```
https://www.ipss.go.jp/pp-shicyoson/j/shicyoson23/3kekka/Municipalities/13.xlsx
```

| 項目 | 実測 |
|---|---|
| 形式 | xlsx（openpyxl で読める） |
| 構造 | **シート63枚＝東京都＋区市町村62**。シート名は `13101_千代田区` 形式 |
| 粒度 | 男女計／男／女 × 5歳階級 × 2020・2025・2030・2035・2040・2045・2050 |
| 行の位置 | `総数`／`（再掲）65歳以上`／`年齢別割合（65歳以上：％）` が固定行にある |
| 2020年の扱い | **実績値（国勢調査）**。2025年以降が推計 |
| 打ち切り | **2050年で切れる。2050年より先へ外挿しない** |

これで出せたもの（T3・T4）:
- 都全体の高齢化率 2020年 22.7% → 2050年 29.6%
- 都の2050年水準を **2020年時点で既に超えている自治体が62中11**（最高＝檜原村 53.1%・65歳以上1,064人）
- 46%（全国が2100年に到達するとされる水準）へ推計期間内に到達するのは4自治体
  （檜原村・奥多摩町は2020年に到達済み、青梅市2045年、日の出町2050年）
- パイロット候補上位5が全部西多摩で隣接。合算で2050年に人口245,244人・高齢化率44.5%

再現スクリプト: `Agent-team/tools`（Lab側）に `t3_t4_arrival.py`。引数なしで社人研から取り直して同じ表を出す。

## C. 探したが公開されていないもの（推定で埋めない）

パイロット地選定に必要な20項目のうち、**11項目は都内62区市町村を横並びに採点できるだけの
公開データが無い**（カタログ全9,678件・2026-07-04取得への部分一致件数。判定は「件数 < 62」）。

| 足りない項目 | 件数 |
|---|--:|
| 就労・シルバー人材 | 49 |
| 文化財・伝統工芸 | 48 |
| バリアフリー | 13 |
| 敬老・老人クラブ | 10 |
| 公衆浴場・銭湯 | 8 |
| 商店街 | 3 |
| 熱中症・暑さ対策 | 3 |
| クーリングシェルター | 3 |
| 認知症 | 2 |
| 温泉 | 1 |
| **空き家・空き店舗** | **0** |

足りている9項目は 人口936／年齢別町丁別233／公園トイレ220／交通215／避難所151／
高齢者129／介護施設121／将来人口108／医療機関72。

**傾向**: 足りているのは「人が何人いるか」と「施設がどこにあるか」。
足りないのは「そこで暮らしが成り立つか」。ただし A-2 が反例なので、**「無い」と断定せず
「62自治体を横並びに採点できない」と書く。**

### C-1. 特に、公式に募った声に対してデータが無いもの

公式テーマ07の都民の声 **「地域貢献・社会貢献の機会と自身の強み・適性とのマッチング」** に対し、
事務局が挙げた関連ODは NPO法人情報／労働力統計／就業者数の予測／都立スポーツ施設／生涯学習センター。
**5件とも「機会がどこにあるか」であって「誰が何に向いているか」ではない。**

適性・職務適合を表す公開データは見つかっていない。HaaS 型のマッチングUIを不採用にした判断は、
事務局のリスト自身がその根拠になっている。**推定で適性データを合成しない。**

## D. カタログの引き方（再現用）

```bash
UA="Mozilla/5.0 (X11; Linux x86_64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/128.0.0.0 Safari/537.36"
curl -s -A "$UA" \
  "https://catalog.data.metro.tokyo.lg.jp/api/3/action/package_search?q=$(python3 -c 'import urllib.parse;print(urllib.parse.quote("高齢者等の異変"))')&rows=3" \
  | python3 -c "import json,sys;d=json.load(sys.stdin)['result'];print(d['count']);[print(p['title'],p['name'],[(r['format'],r['url']) for r in p['resources']]) for p in d['results']]"
```

公式サイトのテーマ・都民の声・関連ODの全文（12テーマ／課題57件／データ61件）は
Drive の応募済フォルダに『20260823-都知事杯2026-公式テーマと関連オープンデータ全一覧』として置いてある。
