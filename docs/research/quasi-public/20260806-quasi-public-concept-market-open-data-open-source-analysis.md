# 準公共概念の理論・制度・オープン性に関する比較研究

> 原文: [Google Docs](https://docs.google.com/document/d/1sDiK2pc4Z4kDLApQywZZAwDZxvFeQkmgaCgUIbUQMyU)

**報告日:** 2026年8月6日

## エグゼクティブサマリー

「準公共」は、公共と市場の中間にある単一の制度類型ではない。本報告は、同概念を、**財・サービスの性質**、**組織の性質**、**ガバナンスの性質**という三層に分解する。第一層では、非排除性・非競合性が完全ではない「準公共財」または「不純公共財」を指す。第二層では、公的使命と商業的活動、公的所有と民間経営、税財源と利用料金などを組み合わせるハイブリッド組織を指す。第三層では、政府、市場、非営利組織、市民コミュニティが、規制、契約、共同生産、ネットワーク、コモンズを通じて共同統治する制度配置を指す。

したがって、「準公共」を供給主体の法人格だけで判定することはできず、**誰が所有するか、誰が払うか、誰が決めるか、誰が利用できるか、誰が最終責任を負うか**を分けて検討する必要がある。サミュエルソンの集合消費財、ブキャナンのクラブ財、オストロムらの財分類と多中心的統治、ウィリアムソンの市場・ハイブリッド・階層の比較制度分析は、この多層的理解の理論的基礎を与える。

公共と市場は、対称的な二つの「部門」ではない。公共財は消費属性に関する概念であり、公的供給は所有・統治に関する概念である。一方、市場は価格と契約を通じた配分制度である。政府は排除可能で競合的な医療・介護等を供給し得るし、民間企業やコミュニティは非競合的なデジタル基盤を供給し得る。このため、公共財、市場の失敗、価値財、外部性、公益事業、準市場、PPP、第三セクターを同義に扱うべきではない。

日本の準市場論が示すように、準市場は、公的資金で利用者の購買力を補い、利用者選択と供給者競争を導入する制度であり、財の属性としての準公共財とは別概念である。

オープンデータとオープンソースは、準公共と親和的だが同義ではない。オープンデータはデータ・コンテンツに対するアクセス、利用、改変、再配布の権利を、オープンソースはソースコードの入手可能性に加え、利用、改変、派生物、再配布の権利をライセンスで保障する。これらは主として**法的・技術的な排除可能性を低下させる設計**であるのに対し、準公共は公共目的、資金、統治、責任配分を含む制度設計である。

したがって、政府が公開するデータでも住民が意思決定に参加できるとは限らず、企業主導のオープンソースでも公共的な再利用価値を持ち得る。逆に、公共性の高い住民基本台帳や水道制御系は、プライバシーや安全保障上、全面公開すべきではない。オープン性は「公共か市場か」と直交する設計軸として扱うべきである。

事例比較では、日本郵政のユニバーサルサービス、宮城県の「みやぎ型管理運営方式」、エストニア発のX-Road、OpenStreetMapを選定した。四事例はいずれも、公共価値を民間能力・利用料金・コミュニティ・オープンライセンスと組み合わせるが、責任構造は異なる。

日本郵政は法定義務と政府保有を残す企業型、宮城県は資産所有と最終責任を公共側に残す長期官民契約型、X-Roadは国家の信頼基盤とオープンソース開発を組み合わせるデジタル公共インフラ型、OpenStreetMapは非営利財団と世界的コミュニティがオープンデータ・コモンズを維持する型である。成果を評価する際は、費用削減や利用者数だけでなく、普遍的アクセス、公平性、品質、レジリエンス、民主的正統性、退出可能性、保守資金、知識継承を同時に測る必要がある。

政策面では、短期に「準公共性評価票」と公共価値KPIを導入し、契約・ライセンス・意思決定権・最終責任を可視化することが重要である。中期には、共有デジタル基盤への共同拠出、上流オープンソースへの調達評価、独立モニタリング、利用者・市民参加、相互運用性を制度化する。長期には、社会的に不可欠な準公共デジタル基盤を識別し、サービス継続、データ移転、保守責任、セキュリティ、透明性について最低義務を設けるべきである。

オープン化は無償化ではなく、保守・品質管理・セキュリティ・コミュニティ運営という継続費用を伴うため、ライセンス選択と同時に持続可能な資金モデルを設計しなければならない。Linux Foundationの調査も、オープンソースへの組織的投資の大部分が労働投入であることを示しており、公開しただけでは持続しない。

## 調査範囲・方法と概念上の前提

### 調査範囲と資料選定

本報告は、経済学、公共経営論、組織論、公共政策論、デジタル・ガバナンス論を横断する。資料は、査読論文、政府・自治体・国際機関の政策文書、法令・契約・事業報告、プロジェクト財団の規約・会計資料を優先した。

概念については、サミュエルソン、ブキャナン、オストロム、ウィリアムソン、パウエル、ムーア等の基礎文献を起点とし、日本語圏では準公共財、公益事業、準市場、PPP、オープンデータに関する学術・政策資料を参照した。

事例は、次の基準で選定した。

第一に、普遍的アクセス、基礎インフラ、社会的外部性、情報基盤など明確な公共目的を持つこと。第二に、政府、市場、非営利組織、コミュニティのうち複数が統治・資金・実装に関与すること。第三に、実装形態、成果、課題を一次資料で追跡できること。第四に、日本と海外を各二例以上含み、物理インフラとデジタル基盤、法定企業とPPP、オープンソースとオープンデータ・コモンズを比較できること。第五に、単なる成功事例集ではなく、持続可能性や説明責任上の緊張も観察できること、とした。

### 分析単位

分析単位を混同しないため、本報告では「公共性」を次の四つに分ける。

| 分析単位 | 問うべきこと | 代表概念 |
| :-- | :-- | :-- |
| 財・サービス | 他者を排除できるか、利用が他者の利用を減らすか | 公共財、私的財、クラブ財、共有資源 |
| 価値・目的 | 何を社会的に保障し、誰の厚生・権利を優先するか | 公共価値、普遍性、公平性、権利、レジリエンス |
| 組織 | 誰が所有し、雇用し、投資し、収益・損失を負担するか | 行政組織、公企業、営利企業、非営利法人、ハイブリッド組織 |
| ガバナンス | 誰がルールを定め、監督し、異議申立てを受け、最終責任を負うか | 規制、契約、ネットワーク、多中心的統治、コモンズ |

この分解は、財の属性と供給主体を分離したオストロムらの議論、取引特性に応じて市場・ハイブリッド・階層を比較するウィリアムソンの議論、公的価値・正統性・実行能力の整合を問うムーアの戦略三角形と整合する。

### 本報告における作業定義

本報告では、**準公共**を次のように定義する。

> *準公共とは、財・サービスの利用特性、公共目的、資金調達、所有、意思決定、説明責任のいずれか複数において、公的原理と市場・共同体原理が制度的に結合され、単一主体による完全な統制でも純粋な価格取引でも適切に供給・維持できない状態、組織またはガバナンス配置である。*

この定義は、準公共を「公共と民間の中間点」に固定せず、複数軸上の組合せとして捉える。したがって、準公共性は恒久的な本質ではなく、料金徴収技術、暗号化、混雑、規制、ライセンス、社会規範によって変化する。

たとえば道路は空いている間は低競合だが混雑すると競合的になり、料金所や電子課金により排除可能性も変わる。データやコードは複製時には非競合的でも、信頼できる更新、計算資源、セキュリティ対応、意思決定権は希少で競合的である。財の排除性と共同利用性を連続的・制度依存的に捉える見方は、クラブ財論と多中心的制度論に支えられる。

## 主要定義と概念史

### 公共財から準公共財へ

サミュエルソンは1954年、各人の消費が他者の消費可能量を減らさない「集合消費財」を定式化し、私的財の市場均衡とは異なる公共支出の最適条件を示した。後の標準的整理では、公共財は非競合性と非排除性を持つ財とされる。日本の政策・研究資料でも、非競合性と排除不可能性が公共財の基本特性として採用されている。

ただし現実の財は二分法に収まらない。ブキャナンの1965年のクラブ理論は、一定の集団内で共同消費できる一方、会員制や料金で非会員を排除でき、利用者増加により混雑が生じる財を扱った。オストロム夫妻は、排除の難易度と利用の控除性・共同性を分け、私的財、公共財、クラブ的財、共有資源を区別した。

日本語の「準公共財」は、非競合性または非排除性が不完全な財、あるいは純粋公共財と私的財の間にある財を指す用法が一般的であるが、文献によりクラブ財、混雑財、外部性を伴う公益的サービスまで含む範囲が異なる。

基本的な財分類は次のとおりである。

|  | 排除が容易 | 排除が困難 |
| :-- | :-- | :-- |
| **競合的・控除的** | 私的財：食料、専有設備 | 共有資源：漁場、地下水、混雑した共有空間 |
| **非競合的または低競合** | クラブ財・料金財：会員サービス、有料道路、サブスクリプション型デジタル財 | 純粋公共財：国防、基礎的な警報情報、非混雑下の知識 |

この表でいう「準公共財」は単一セルではなく、主としてクラブ財、混雑する公共財、排除技術によって性質が変わる財を覆う便宜的総称である。

外部性は第三者への便益・費用、価値財は社会的に望ましい消費を政策的に保障する規範判断であり、非排除性・非競合性とは別の論点である。介護のように競合的・排除可能でも、公平性、情報の非対称性、正の外部性、権利保障によって公的介入が正当化される財がある。

### 供給主体からハイブリッド統治へ

1980年代以降の民営化、規制改革、PPP、New Public Managementの展開により、「公共」は政府直営、「民間」は市場供給という対応関係が崩れた。ウィリアムソンは1991年、市場と階層の間に独自の契約・調整・適応様式を持つハイブリッドを置いた。パウエルは市場でも階層でもないネットワークを、相互依存、反復的関係、相互コミュニケーションに基づく統治形態として論じた。

近年の公共・民間ハイブリッド組織研究は、所有、資金、統制、制度論理、成果の各次元で混合が生じることを整理している。

この流れでは、準公共性は財の技術的性質だけでなく、組織の「複数使命」と「複数の説明責任」に現れる。公企業、第三セクター、社会的企業、PPP、指定管理、公益事業、非営利プラットフォームは、利益、費用回収、普遍的サービス、公平性、地域維持、イノベーション等を同時に追求する。

しかし、目標が多いほど、成果の曖昧化、責任の分散、ミッション・ドリフト、利益の私有化と損失の社会化、規制の虜、情報非対称が生じやすい。ハイブリッドは自動的に「官の公平性と民の効率性の最良部分」を実現するのではなく、権限・リスク・収益・データの配分を明示して初めて機能する。

### 準市場との区別

準市場は「準公共」と語感が近いが、理論的位置が異なる。準市場は、医療、介護、教育、保育などで、利用者の購買力を税・社会保険・バウチャー等の公的資金で補い、複数供給者からの選択と供給者間競争を導入する制度である。

日本では1920年代の医療保険に先行形態が見られ、1990年代以降、介護・障害福祉・保育等に拡大したとされる。期待される効果は利用者選択、質改善、効率化だが、参入退出、情報支援、低所得者の選択能力、クリーム・スキミング防止、供給空白への対応が必要である。

したがって、準市場は**公共目的を市場的配分手段で追求する制度**であり、準公共財は**財の属性が純粋公共財と私的財の中間にある状態**である。両者は重なる場合があるが、同義ではない。

たとえば介護は準市場で供給されても、利用自体は競合的で排除可能である。反対に、オープンな地理データは準公共財的であっても、利用者が供給者を選ぶ準市場とは限らない。

### 概念史の統合

> 原文には概念史のタイムライン図が含まれていた（Google Docs のエクスポートでラベルのみが残ったため、以下の年表で置き換える）。

| 年 | 理論・潮流 | 要点 |
| :-- | :-- | :-- |
| 1954 | Samuelson「集合消費財」 | 公共支出の純粋理論 |
| 1965 | Buchanan「クラブ理論」 | 排除可能・低競合・混雑 |
| 1977 | Ostrom & Ostrom | 排除性と共同利用性による財分類 |
| 1990 | Powell「ネットワーク」 | 市場でも階層でもない統治 |
| 1991 | Williamson「ハイブリッド」 | 市場・混合・階層の比較制度分析 |
| 1990年代 | 準市場・PPP・公共価値論 | 選択、競争、正統性、実行能力 |
| 2000年代以降 | オープンデータ・OSS・デジタル公共インフラ | ライセンスと共同生産による開放 |

この概念史から得られる重要な帰結は、準公共を単なる「官民比率」で表せないことである。公共性は、財の利用特性、価値判断、組織形態、統治機構、オープン性の組合せから生じる。

オストロムの多中心的統治は、市場か国家かという二分法を超え、異なる規模の複数意思決定主体が、相互監視、学習、調整を行う制度が現実に存在することを示した。

## 理論的枠組みと公共・市場との比較

### 理想型比較

以下の表は、「公共」を民主的・法的統制を受ける公的供給の理想型、「市場」を価格・契約・競争を中心とする理想型、「準公共」を複数原理の制度的混合として比較したものである。現実の制度は各列の特徴を組み合わせる。

| 属性 | 公共 | 市場 | 準公共 |
| :-- | :-- | :-- | :-- |
| **財の排除性・競合性** | 非排除・低競合の財への対応に強いが、権利保障や価値財として私的財も供給 | 排除可能・競合的で価格付けしやすい財に強い | 排除性・競合性が部分的、混雑・ネットワーク効果・外部性・技術変化を伴う |
| **配分原理** | 法的資格、必要性、普遍性、行政判断、民主的優先順位 | 支払意思・支払能力、価格、契約、競争 | 公的資格＋利用料金、バウチャー、会員制、規制価格、共同ルール |
| **ガバナンス** | 法令、議会、行政階層、監査、司法・不服申立て | 所有権、会社統治、契約、競争法、破産・退出 | 規制契約、PPP、公企業、財団、協議会、ネットワーク、多中心的統治 |
| **資金調達** | 税、社会保険料、公債、一般・特別会計 | 売上、出資、融資、広告、知財収入 | 税＋料金、交付金、補助、拠出金、会費、寄付、企業支援、クロスファイナンス |
| **目的・価値** | 権利、公平、普遍性、公共価値、長期安定、危機対応 | 利益、顧客価値、効率、革新、選択 | 社会的使命と事業継続、公共価値と費用回収、共有価値 |
| **説明責任** | 有権者、議会、監査機関、裁判所、住民 | 株主、顧客、債権者、規制当局 | 複数プリンシパルに対する重層的説明責任 |
| **情報・透明性** | 情報公開、予算・決算、行政手続。ただし機密・個人情報制約 | 契約・企業秘密が中心。上場・規制分野は開示義務 | 公的開示と営業秘密の境界が争点。契約・アルゴリズム・KPIの可視化が必要 |
| **参加・発言** | 選挙、パブリックコメント、審議会、請願、不服申立て | 購買、退出、レビュー、株主権 | 利用者選択、市民委員、共同設計、コミュニティ貢献、異議申立て |
| **代表的失敗** | 官僚制、硬直性、政治的短期主義、予算最大化、供給者独占 | 外部性、公共財不足、独占、情報非対称、不平等、短期利益偏重 | 責任の空洞化、ミッション・ドリフト、クリーム・スキミング、契約硬直、捕捉、維持費不足 |
| **適合条件** | 権利・安全・普遍性が強く、退出を許容しにくい領域 | 品質を比較でき、競争・退出が機能し、損害が内部化される領域 | 公的保障と専門能力・革新・共同生産の双方が必要な領域 |

表の理論的根拠は、公共財論、準市場論、取引費用論、ネットワーク論、多中心的統治論、公共価値論である。公共価値論の戦略三角形は、価値ある目的だけでなく、正統性・支持と実行能力の同時成立を要求するため、準公共事業の評価に適している。

### 準公共性を測る多軸モデル

準公共性を一つの連続尺度に縮約すると、重要な差異が失われる。本報告は少なくとも次の七軸で評価する。

| 評価軸 | 低い側 | 高い側 | 診断質問 |
| :-- | :-- | :-- | :-- |
| アクセス公共性 | 支払者・会員限定 | 普遍的アクセス | 地域、所得、障害、年齢で排除されないか |
| 消費共同性 | 強い競合 | 低競合・反復利用 | 一人の利用が他者の利用をどの程度減らすか |
| 目的公共性 | 私的利益中心 | 権利・公平・社会的便益中心 | 何を公共価値として保障するか |
| 資金公共性 | 商業収入中心 | 税・公的拠出中心 | 不採算利用者を誰が負担するか |
| 統治公共性 | 私的裁量中心 | 民主的・法的統制中心 | ルール変更者と異議申立て先は誰か |
| 知識公共性 | 閉鎖仕様・専有知財 | オープン標準・再利用可能 | データ、コード、仕様を再利用・監査できるか |
| 責任公共性 | 責任分散・限定 | 最終責任が明確 | 障害、撤退、破綻時に誰が継続するか |

このモデルでは、同じ事業でも軸ごとに位置が異なる。民間運営の水道は、組織・資金面では市場寄りでも、アクセス義務、料金規制、最終責任は公共寄りであり得る。企業主導OSSは、知識公共性が高くても、ロードマップ決定や資金支配は私的であり得る。この非対称性こそが、準公共を独立した分析対象とする理由である。

### 規範的評価基準

準公共制度の正当性は、効率性だけでは判断できない。最低でも、次の要素を評価すべきである。

- アクセスと公平
- サービス品質と安全
- 費用対効果
- 長期的な維持可能性
- 透明性と異議申立て
- 供給者の退出・破綻へのレジリエンス
- データ・知識の可搬性
- 将来世代への資産・負債移転

特に、準公共制度は複数主体が関与するため、「契約上の履行責任」と「政治的・道義的な最終責任」が分離しやすい。契約で民間へ業務を移しても、生命・生活に不可欠なサービスの最終責任まで消えるわけではない。宮城県が資産所有と事業の最終責任を保持する設計は、この原則を明示した例である。

## オープンデータ・オープンソースとの比較

### 概念とライセンス

Open Definitionは、データ・コンテンツのオープン性を、誰もが目的を問わずアクセス、利用、改変、再配布できることとして定義し、帰属表示や同一条件での共有のような限定的条件のみを許容する。

OSIのOpen Source Definitionは、自由な再配布、ソースコード、改変・派生物の許可、個人・集団・利用分野への差別禁止等を求める。単に閲覧できる「ソース・アベイラブル」は、改変・再配布の権利がなければオープンソースではない。

日本の公共データ利用規約第1.0版はCC BY 4.0と互換であり、国・自治体のウェブサイトやオープンデータに適用できる。2024年改定のオープンデータ基本指針は、原則として二次利用を促進し、検索・利用しやすい公開、一括ダウンロード、API提供を推進する。

ここから、オープンデータにはライセンスだけでなく、機械可読性、検索性、更新性、API、メタデータ等の技術的実装が必要だと分かる。

### 比較表

| 観点 | 準公共 | オープンデータ | オープンソース |
| :-- | :-- | :-- | :-- |
| **理念** | 公共目的と市場・共同体能力を組み合わせ、普遍性と持続性を両立 | データの再利用により透明性、説明責任、研究、革新、サービス改善を促す | ソースコードを利用・研究・改変・再配布可能にし、共同開発と再利用を促す |
| **主対象** | 財、サービス、組織、インフラ、制度 | データベース、統計、地理情報、文書、API | ソースコード、ビルド手順、依存関係、開発プロセス |
| **法的基盤** | 法令、規制、契約、定款、サービス義務。固有のライセンス要件はない | CC0、CC BY、ODbL、公共データ利用規約等 | MIT、Apache-2.0、BSD等の許容型、GPL・AGPL等のコピーレフト |
| **排除性への作用** | 補助、規制、普遍的サービス義務等で社会的排除を抑制 | 法的・技術的な再利用排除を低下 | コード利用・改変・再配布の法的排除を低下 |
| **ガバナンス** | 行政、規制者、事業者、住民、非営利組織等の複合統治 | データ保有機関主導が多い。標準団体、利用者、データ共同体が参加する場合もある | メンテナー主導、財団主導、企業主導、コンソーシアム型等、多様 |
| **利害関係者** | 納税者、利用者、住民、従業員、企業、規制者、将来世代 | データ主体、保有機関、再利用者、研究者、企業、市民、監督機関 | メンテナー、コントリビューター、利用企業、クラウド事業者、財団、セキュリティ研究者 |
| **資金・持続可能性** | 税、料金、拠出金、補助、投資、会費等の混合 | 行政予算、助成、委託、利用者支援。更新・品質・API運用費が必要 | 企業の人件費、寄付、スポンサー、会費、サービス収入、助成。無償労働依存が課題 |
| **透明性** | 法令・契約・KPIの開示次第。官民境界で営業秘密との緊張 | データ公開は高透明性に寄与するが、収集方法・欠測・意思決定過程が不透明な場合がある | コード・課題・履歴を監査しやすいが、非公開会議や事実上の支配構造は別問題 |
| **参加性** | 選挙、審議会、利用者協議、共同生産、選択・退出 | フィードバック、データ要求、共同整備、データソン。ただし公開だけでは共同統治にならない | issue、pull request、レビュー、フォーク。ただし技術力・時間・言語・権限格差がある |
| **持続可能性上の主要リスク** | 目標衝突、責任分散、契約硬直、赤字・撤退、政治的捕捉 | 更新停止、品質劣化、個人情報漏えい、再識別、標準不統一、利用格差 | メンテナー疲弊、依存集中、サプライチェーン脆弱性、企業による影響集中、ライセンス変更 |
| **公共性との関係** | 公共性そのものを制度化する分析概念 | 公共性を高め得る手段だが、公開主体・用途は官民を問わない | 公共的再利用を可能にする手段だが、公共目的・民主的統治を自動的には保証しない |

表のライセンス要件はOpen Definition、OSI、デジタル庁の一次資料に基づく。持続可能性に関して、Linux Foundationの2024年調査は組織によるOSS投資の大部分が労働価値であると報告しており、資金額だけでなく、保守時間、レビュー能力、セキュリティ対応を測る必要がある。

### オープン性は公共性と直交する

> 原文にはこの直交性を示す2×2の図が含まれていた（Google Docs のエクスポートでラベルのみが残ったため、以下の表で置き換える）。

縦軸＝統治・目的の軸（公共目的・民主的責任が強い ↔ 私的目的・所有者裁量が強い）、横軸＝アクセス・再利用の軸（オープン＝再利用・改変可能 ↔ クローズド＝利用・再配布を制限）。準公共は各象限を横断し得る（規制・契約・共同統治）。

|  | オープン | クローズド |
| :-- | :-- | :-- |
| **公共目的・民主的責任が強い** | 政府オープンデータ、公共OSS | 個人情報台帳、安全保障・制御系 |
| **私的目的・所有者裁量が強い** | 企業主導OSS、公開API・データ | 専有ソフト、囲い込み型プラットフォーム |

公共性が高い情報でも、個人情報、営業秘密、重要インフラ、サイバーセキュリティに関するデータはアクセス制御を要する。一方、MITライセンスのような許容型OSSは、商用・クローズド製品へ組み込むことも認める。

X-Roadがオープンソースでありながら、実際の行政データを無制限に公開せず、認証・署名・ログを伴う組織間交換基盤として使われる点は、**コードのオープン性とデータの機密性を分離する設計**の代表例である。

### 透明性と参加性の限界

オープンデータの公開は、何が起きたかを検証する材料を増やすが、データ項目の選定、収集方法、欠測処理、モデル化、予算配分の決定権までは開かない。OSSもコードを読めることと、ロードマップやマージ権限を共有することは異なる。

透明性は「成果物の可視性」、参加性は「意思形成への影響力」、説明責任は「理由提示と是正可能性」であり、別々に評価すべきである。OECDのオープンガバメント論も、透明性、説明責任、市民参加を相互に関連しつつ区別される原則として扱う。

ライセンス選択にも価値判断がある。CC0、MIT、Apache等の許容型は再利用障壁を下げ、民間実装を広げやすいが、改良成果を共有資源へ戻す義務は弱い。GPL、AGPL、ODbL等の相互性・継承型ライセンスは、派生物または派生データベースの共有を促す一方、他ライセンスとの互換性や企業利用の設計が複雑になる。

OpenStreetMapがODbLを採用し、EU等のCC BY系データとの互換性を事前に検討するよう注意喚起していることは、法的オープン性だけでなく「組み合わせ可能性」が実務上重要であることを示す。

### 事例全体の位置づけ

| :-- | :-- | :-- | :-- | :-- |
| 日本郵政・日本郵便 | 日本・郵便／地域拠点 | 法定ユニバーサルサービス＋企業経営 | 政府保有を残す上場持株会社と事業会社、法定サービス義務、拠出・交付金 | 業務データの一部は公開、基幹運営は専有的 |

### 日本郵政・日本郵便

日本郵政グループは、株式会社として収益・資本効率を求められながら、郵便、郵便貯金、簡易生命保険に関するユニバーサルサービスと郵便局ネットワーク維持を担う。

政府保有割合は2026年5月末時点で発行済株式の35.5%と報告され、制度上も政府保有は常時三分の一超とされる。約2万局の郵便局でユニバーサルサービスを利用可能にするネットワークが制度の基礎であり、金融二社の拠出金を原資とする交付金制度もネットワーク維持を支える。これは、公共目的、法的義務、政府所有、企業収益、グループ内拠出を組み合わせた企業型準公共モデルである。

成果は、全国的な物理拠点と配送網を維持し、市町村・過疎地域を含むアクセスを制度的に担保している点にある。他方、デジタル化、人口減少、郵便物数・窓口来客数の減少、コスト上昇により、ユニバーサルサービスと企業価値を同時に維持することが経営課題となっている。

2026年策定の中期計画も、ユニバーサルサービスの持続性確保と新事業領域の成長を同時目標に掲げる。ここでは、公共目的が明確でも、費用負担の帰着、局網の適正規模、デジタル代替と対面アクセス、地域政策との役割分担が継続的な政治判断となる。

評価指標としては、人口・面積当たり郵便局数、最寄局までの移動時間、過疎地のサービス継続率、配達品質、苦情・事故、ユニバーサルサービス純費用、交付金依存度、局別採算だけでなく地域波及効果、デジタル利用が困難な層のアクセス、災害時の拠点機能を組み合わせるべきである。

局数や利益だけでは、ネットワークが生むオプション価値、地域安全網、危機時の代替能力を捉えられない。

### みやぎ型管理運営方式

宮城県の上工下水一体官民連携運営事業は、県が認可上の事業者、施設所有者、管路管理者、最終責任主体であり続けつつ、民間事業者が設備の維持管理、改築、経営管理等を長期的に担うコンセッション型の制度である。

完全民営化とは異なり、公共側に資産・認可・最終責任を残し、民間側に運営権と性能達成責任を配分する。県はセルフモニタリング、県モニタリング、第三者評価等を組み合わせ、要求水準違反時の改善・措置を制度化している。

宮城県が2025年10月に公表した事業開始後3年の評価では、20年間の予定削減額は従来方式比約337億円、物価変動等を踏まえた時点見込みは約356億円で、事業は概ね計画どおりとされた。県の経営戦略は、同方式の導入効果もあり、2024年度から水道用水供給料金を値下げしたと記載する。

もっとも、長期見込みは反実仮想となる「現行体制モデル」の仮定に依存し、将来の物価、更新需要、災害、技術、人件費を含むため、削減額だけで成功を確定すべきではない。

課題は、二十年契約の不完備性、公共側の監督能力維持、事業者と県の情報非対称、災害・水質事故時の指揮、設備更新の先送り防止、契約終了時の人材・データ・設備状態の引継ぎである。

KPIには、水質目標、需要予測、設備・センサー、エネルギー効率、人材育成、顧客満足、地域企業活用などを含め、費用削減と同じ重みで公開する必要がある。県資料がKPIと三重のモニタリングを採用していることは、準公共PPPでは「民間化」よりも「監督可能性の設計」が核心であることを示す。

評価指標は、水質基準適合率、断水・事故件数、復旧時間、設備健全度、更新投資の計画達成率、漏水・エネルギー原単位、ライフサイクル費用、料金負担、苦情処理、監査指摘、地域雇用、人材資格、引継ぎ可能性、契約変更回数を含むべきである。

### X-Road

X-Roadは、行政機関や民間組織の情報システム間で、安全にデータを交換する分散型基盤である。データを一つの中央データベースに集約するのではなく、各組織が保有したまま、認証、暗号化、電子署名、ログ等を伴う交換を可能にする。

コアソフトウェアはMITライセンスのオープンソースであり、商用・クローズド製品への組込みも可能である。制度としては国家・参加組織が信頼規則と認証を担い、技術としては再利用可能なOSSを使うため、「公共ガバナンス」と「オープンな実装資産」を分離・接続したモデルである。

NIISの年次資料によれば、2024年末までに少なくとも25か国でX-Road技術が採用され、国際コミュニティは約4,400人、162か国に広がったとされる。専門家グループがロードマップやバックログに意見を与える仕組みもある。

これは、政府が個別に専有システムを調達するよりも、共通コアを国際的に再利用し、改善知識を共有できる可能性を示す。エストニアとフィンランドの人口登録間自動交換のように、国境を越える信頼連携にも拡張されている。

ただし、コードがオープンでも、制度導入には認証局、法的根拠、データ責任者、セキュリティ運用、標準化、参加機関の能力が必要である。OSS採用国数は社会的成果そのものではなく、行政手続時間、重複入力削減、データ品質、障害・不正アクセス、復旧時間、利用者の同意・通知、越境時の法的整合性を別途測定しなければならない。

また、コア開発者・資金提供国への依存と、各国独自改変による分岐も長期課題である。

評価指標は、接続組織・サービス数、トランザクション成功率・遅延、稼働率、セキュリティ事故、監査ログ完全性、重複データ提出削減、行政処理時間、国際共同開発への貢献数、未解決脆弱性、フォーク間互換性、単一ベンダー依存度を含むべきである。

### OpenStreetMap

OpenStreetMapは、世界の参加者が地理情報を共同編集し、ODbLの下で再利用可能なデータとして提供するオープンデータ・コモンズである。

OpenStreetMap Foundationは、プロジェクトを「統制」する主体ではなく、法的、技術的、財務的な基盤を支援する国際非営利法人と位置づけられる。公開データ、ボランティア共同生産、財団、企業利用者、寄付者、地域コミュニティが相互依存するため、国家でも企業でもない準公共デジタル基盤の代表例である。

成果として、登録利用者は1,000万人を超え、世界規模の地理データを反復利用可能にしている。ただし登録者数はアクティブ編集者数を意味せず、地域別の網羅性、更新頻度、属性精度には差がある。

財団は公開理事会を原則月次で開催し、会員による傍聴・質問を認め、財務資料を公開するなど透明性を重視している。

持続可能性は自動的ではない。OSMFの2024年度会計では、売上高に相当する収入が約47万ポンド、営業赤字が約8.8万ポンド、流動負債控除後資産が約60.9万ポンドであった。財務報告では寄付キャンペーンの弱さと、おおむね一年分の準備金維持への懸念も示された。

世界的な利用価値に比べ、コア運営組織の財務規模が小さいことは、オープンな共有資源が巨大な下流便益を生んでも、その維持主体に十分な資金が還流しない「価値獲得ギャップ」を示す。

課題は、地域・属性別のデータ格差、参加者の代表性、編集紛争、荒らし、企業編集とコミュニティ自治の均衡、ODbLと他データライセンスの互換性、サーバー・スタッフ・法務の持続資金である。

評価指標は、月間アクティブ編集者、地域別完全性・正確性、変更反映時間、破壊的編集の復旧時間、API稼働率、理事・作業部会の多様性、企業・個人資金の集中度、準備金月数、ライセンス違反対応、下流大口利用者からの還元を含むべきである。

### 横断比較

| 比較点 | 日本郵政 | みやぎ型 | X-Road | OpenStreetMap |
| :-- | :-- | :-- | :-- | :-- |

| 主な成果 | 物理的ユニバーサル網の維持 | 費用削減見込み、料金引下げ、統合管理 | 多国展開、再利用、越境連携 | 世界規模の共同地図データ |
| 中核リスク | 需要減と固定網費用、公共使命と収益の緊張 | 長期契約・監督能力・引継ぎ | セキュリティ、法制度整合、コア依存 | 資金不足、地域格差、代表性、品質 |
| 評価上の注意 | 局数・利益だけでは公共価値を過小評価 | 見込み削減額と実績・品質を分離 | 採用国数と住民成果を分離 | 登録者数と実働・品質を分離 |

四事例に共通するのは、公共価値を生む「利用可能性」と、それを支える維持能力が別の資源である点である。ネットワーク、設備、コード、データは利用時の限界費用が低くても、固定費、更新、監視、セキュリティ、人材継承には継続費用がかかる。

準公共制度の要点は、利用を広げる仕組みだけでなく、維持費を公平かつ予見可能に回収し、破綻時の責任を明確にすることである。

## 政策的含意・実務的推奨と研究課題

### 政策的含意

第一に、公共性を法人格で判定してはならない。株式会社であっても法定ユニバーサルサービスを担い得る一方、行政が保有するデータでも再利用不能、更新停止、意思決定不透明であれば知識公共性は低い。政策評価は所有主体ではなく、アクセス、目的、資金、統治、知識、責任の多軸で行うべきである。

第二に、効率性と公共価値を単一KPIへ統合してはならない。費用削減は重要だが、不採算地域の切捨て、保守先送り、品質低下、従業者負担増によって達成される可能性がある。財務、アクセス、公平、品質、レジリエンス、参加、保守負債を別々に測り、トレードオフを公開する必要がある。

ムーアの戦略三角形に即せば、価値、正統性・支持、実行能力のどれか一つだけでは持続しない。

第三に、オープン化と機密保護を二者択一にしない。コード、標準、インターフェース、非個人データ、監査情報は可能な限り開放し、個人データ、認証情報、重要インフラ制御は目的限定・権限管理・監査ログの下に置く「層別オープン性」が必要である。

X-Roadはコードの公開と実データの制御を分離する実例であり、日本のオープンデータ基本指針も、合理的に公開できない情報を除き二次利用を促進する原則を採る。

第四に、オープンな成果物の維持費を公共調達・政策金融の対象として明示すべきである。公共機関がOSSを利用しても上流保守へ貢献しなければ、脆弱性対応と人材負担を少数メンテナーへ外部化する。

データ公開でも、更新頻度、メタデータ、API、品質保証、問い合わせ対応を予算化しなければ「公開済みだが使えない」状態になる。

### 未解決の研究課題

**準公共性の動態測定。** 排除性と競合性は技術、規模、混雑、規制で変化する。静的な四分類を超え、時間、地域、利用者属性ごとに「公共性の程度」を測る方法が必要である。

**因果的な制度比較。** PPP、公企業、行政直営、非営利、コミュニティ運営の成果比較は、案件選択、地域条件、政治環境の差に左右される。費用削減見込みではなく、反実仮想を明示した長期パネル、自然実験、契約変更前後比較が必要である。

**複数価値の集約。** 効率、公平、普遍性、品質、レジリエンス、参加をどのように重み付けするかは技術問題ではなく政治問題である。評価指標の選択過程自体の民主的正統性を研究対象にする必要がある。

**オープンな資産からの価値獲得。** 公共資金やボランティアで整備されたデータ・OSSから、下流企業が大きな価値を得る一方、上流維持者へ資金が還流しない場合がある。利用量連動拠出、会員制、調達貢献義務、基金、公共投資の適切な組合せは未確立である。OSMFの小規模な財務基盤と世界的利用の対比は、この論点を具体化する。

**参加の実質性。** 公開会議、GitHub、パブリックコメントが存在しても、専門知識、英語能力、時間、雇用関係、マージ権限の差が影響力を偏らせる。参加人数ではなく、議題設定、拒否権、異議申立て、代表性、提案採用率を測る必要がある。

**AI時代の準公共性。** 学習データ、モデル、重み、推論API、評価データ、計算資源は、それぞれ排除性・競合性・安全性が異なる。「オープンモデル」をOSSと同一視せず、データ権利、再現可能性、計算資源、監査可能性、危害対応を分解する枠組みが必要である。

**国際移植可能性。** X-Roadのような技術基盤を導入しても、本人確認、データ保護、行政法、機関間信頼、予算、人材が異なれば同じ成果は出ない。技術移転と制度移転を分離した研究が必要である。
