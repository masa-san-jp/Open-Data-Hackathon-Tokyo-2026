# 2100年の東京の未来予測：公的一次情報を中心とした網羅的整理

## TL;DR
- 東京都は2100年までの人口を約713万人（2020年ピーク約1,335万人から約46%減）と推計しており（「東京の自治のあり方研究会」／都が21世紀末までの人口を推計したのは2012年の初試算が最初）、環境省・気象庁は「4℃上昇シナリオ」で21世紀末の東京の年平均気温が20世紀末比約4.3℃上昇、年間猛暑日は約30日に達すると予測している。
- 経済面ではIMF（2025年10月14日発表の世界経済見通し）が2026年に日本の名目GDPがインドに抜かれ世界5位になると見通し、民間予測（PwC・ゴールドマン・サックス）は2050年〜2075年に日本がトップ10前後まで後退すると予測しているが、2100年を直接対象とした経済予測はほとんど存在しない。
- 本レポートは既公表情報の収集・整理であり、作成者独自の予測・解釈を含まない。人口推計の多くは政策効果を織り込まない趨勢延長型であり、2100年を直接対象とする推計がない項目は入手可能な最長期の公的推計（2050・2065・2070年等）で代替している。

## 冒頭の注記
本レポートは、東京都・国（内閣府・環境省・気象庁・文部科学省・国土交通省・総務省・厚生労働省）・国立社会保障・人口問題研究所（IPSS）・地震調査研究推進本部・国連・IMF等の公表資料を中心に、2100年（および入手可能な最長期）の東京に関する既公表の推計・予測・シナリオを収集・整理したものである。作成者自身の新たな予測・解釈・評価は加えていない。以下の点に留意されたい。
- 人口・世帯の将来推計の多くは、出生・死亡・移動の趨勢を機械的に将来へ投影する「趨勢延長型（コーホート要因法）」であり、政策効果を織り込んでいない。
- 気候の将来予測はIPCCのRCP／SSPシナリオ（排出経路の想定）に基づく条件付きの予測である。
- 2100年を直接対象とする推計が存在しない分野は、対象年次を明示した上で最長期の公的推計を用いている。
- 民間シンクタンクの予測は「民間予測」と明示し、補助的に整理している。

## Key Findings（分野別の要点）
- **環境**：環境省「2100年 未来の天気予報」（2019年7月8日公開、新作版・COOL CHOICE、気象キャスターは小島瑠璃子）は「1.5℃目標未達成」で東京の夏の最高気温43.3℃、冬（2月3日想定）でも最高気温26.0℃と描く。気象庁・文部科学省「日本の気候変動2025」に基づく東京管区気象台の東京都版リーフレット（2025年3月）は、21世紀末の東京都の年平均気温が20世紀末比で2℃上昇シナリオ約1.4℃／4℃上昇シナリオ約4.3℃上昇、年間猛暑日は20世紀末2日→約8日／約30日、熱帯夜は7日→約21日／約62日と予測。
- **人口**：東京都「東京の自治のあり方研究会」推計で2100年約713万人。IPSS令和5年推計で全国は2070年8,700万人。国連（世界人口推計2024年版）は日本の2100年人口を約7,685万人と推計。
- **都市機能**：首都直下地震（M7クラス、30年以内約70%）の新被害想定（2025年12月19日公表）で最悪約1万8千人死亡・経済被害約83兆円。「2050東京戦略」（2025年3月）が3つのシティを軸に据え、生成AIで「22世紀の予言」（100年後予測）を試作。
- **経済**：IMFで2026年に日本はインドに抜かれ名目GDP世界5位。都内総生産（名目）は令和5年度125兆円。
- **住環境**：全国の空き家は2023年に約899.5万戸（過去最高、およそ7戸に1戸）。築40年以上の分譲マンションは2024年末148万戸→2044年末482.9万戸と国交省が推計。

## Details

### 1. 環境

#### 1-1. 環境省「2100年 未来の天気予報」（一次情報：環境省、2019年7月8日公開・新作版）
環境省は地球温暖化対策の普及啓発を目的に「2100年 未来の天気予報」を制作・公開した（COOL CHOICEウェブサイト。監修は気象キャスターネットワーク・国立環境研究所、気象キャスターは小島瑠璃子）。IPCC第5次評価報告書のRCP2.6（1.5℃/2℃目標達成に近い）とRCP8.5（未達成）のケースを想定した、産業革命以前からの気温上昇を1.5℃に抑える目標を「達成した2100年」と「達成できなかった2100年」の夏・冬の天気予報動画（4本構成）である。
- 「1.5℃目標未達成」の場合の夏の最高気温：東京43.3℃（名古屋44.1℃、新潟43.8℃など全国で40℃超）。
- 「1.5℃目標未達成」の冬（2月3日想定）の最高気温：東京26.0℃（冬でも夏日）。
- 台風：中心気圧870hPa、最大瞬間風速90m/sといった想定も提示。
- 熱中症死亡者が1万5千人超にのぼるとの描写を含む。
（注：これは啓発コンテンツであり、精密な地域気候モデル出力そのものではない。数値は動画中の想定値。2019年公開で報道により継続的に引用されている。）

#### 1-2. 気象庁・文部科学省「日本の気候変動2025」および東京都版リーフレット（一次情報：文部科学省・気象庁、2025年3月26日公表）
「日本の気候変動2025 —大気と陸・海洋に関する観測・予測評価報告書—」は、2℃上昇シナリオ（RCP2.6、パリ協定2℃目標達成に相当）と4℃上昇シナリオ（RCP8.5、追加的緩和策なし）の2シナリオに基づく。

**全国（21世紀末＝2076〜2095年平均、20世紀末＝1980〜1999年平均比）：**
- 年平均気温：2℃上昇シナリオで約1.4℃上昇、4℃上昇シナリオで約4.5℃上昇。
- 50mm/h以上の短時間強雨の頻度：2℃で約1.8倍、4℃で約3.0倍。
- 日本近海の平均海面水温：上昇。4℃上昇シナリオでは夏季に北極海の海氷がほぼなくなると予測。
- 観測実績：年平均気温は1898〜2024年で100年あたり1.40℃の割合で上昇。

**東京都版リーフレット（東京管区気象台、令和7年3月）：**
- 東京都の年平均気温：20世紀末比で2℃上昇シナリオ約1.4℃、4℃上昇シナリオ約4.3℃上昇。
- 年間猛暑日（日最高気温35℃以上）：20世紀末2日 → 21世紀末 約8日（2℃）／約30日（4℃）。
- 年間熱帯夜（日最低気温25℃以上）：20世紀末7日 → 約21日（2℃）／約62日（4℃）。
- 関東甲信地方の1時間降水量50mm以上の年間発生回数：20世紀末比で約1.9倍（2℃）／約3.5倍（4℃）。
- 関東の南の年平均海面水温：20世紀末比で約0.97℃（2℃）／約2.88℃（4℃）上昇。
- 東京の観測実績：年平均気温は100年あたり2.6℃上昇。
- 「100年に一回の大雨」（東京：日降水量約299mm）がより頻繁化。

#### 1-3. IPCC第6次評価報告書（AR6）の世界平均気温・海面上昇（一次情報：IPCC、2021〜2023年）
- **世界平均気温（21世紀末、1850〜1900年比）**：SSP1-1.9で約1.5℃、SSP2-4.5で約2.7℃、SSP3-7.0で約3.6℃、SSP5-8.5で約4.4℃。
- **世界平均海面上昇（2100年、1995〜2014年比、可能性が高い範囲）**：SSP1-1.9で0.28〜0.55m、SSP5-8.5で0.63〜1.01m。氷床の急速な融解等を含む低確信度シナリオでは、非常に高い排出シナリオ下で2100年までに2mに近づく可能性も排除できないとされる。

#### 1-4. 東京湾の高潮・洪水リスク（一次情報：国土交通省・内閣府・東京都）
- **ゼロメートル地帯**：東京湾のゼロメートル地帯（朔望平均満潮位以下）は面積116km²、人口176万人（国土交通省・内閣府資料、2016年）。参考：名古屋336km²・90万人、大阪124km²・138万人。
- **高潮浸水想定区域図（想定最大規模）**：東京都港湾局・建設局が2018年3月に初公表、2024年12月に改定。既往最大級の室戸台風級（中心気圧910hPa）を想定し、高潮と河川洪水の同時発生、堤防決壊を見込む。対象17区。
- **浸水規模（H30.3版に基づく代表値）**：17区・浸水面積約212km²、浸水区域内人口約395万人（昼間）、最大浸水深約10m、浸水継続1週間以上（内閣官房・中央防災会議系資料）。
- **江東5区（墨田・江東・足立・葛飾・江戸川）大規模水害**：浸水想定区域内居住人口約250万人、最大浸水深約10m、浸水継続2週間以上（江東5区広域避難推進協議会、2018年8月）。
- （注：東京都の高潮浸水想定区域図はRCP8.5等の気候変動シナリオを直接の前提とするものではなく、水防法に基づく「想定し得る最大規模」を前提とする。）

#### 1-5. 東京都の気候変動対策（一次情報：東京都環境局）
- **ゼロエミッション東京戦略**（2019年策定）：2050年にCO2排出実質ゼロに貢献する「ゼロエミッション東京」を宣言。
- **カーボンハーフ**：2030年までに温室効果ガス排出量を50%削減（2000年比）。
- **ゼロエミッション東京戦略 Beyond カーボンハーフ**（2025年3月策定）：2035年までに温室効果ガス排出量を60%以上削減（2000年比）という新目標と31の個別目標を設定。
- 新築住宅等への太陽光パネル設置義務化（2025年4月施行）、次世代型ソーラーセル（Airソーラー）等の導入。

### 2. 人口

#### 2-1. 東京都の2100年人口推計（一次情報：東京都・「東京の自治のあり方研究会」）
東京都が21世紀末までの人口を推計したのは2012年（日本経済新聞「東京の人口、2100年に半減の713万人 都が初試算」）が最初で、その後「東京の自治のあり方研究会」（都と区市町村・有識者）が推計を継続している。**ベース推計**：
- 総人口：2020年約1,335万人でピーク → 2070年に1,000万人割れ → 2100年約713万人（2010年実績約1,316万人比で約46%減）。
- 老年人口（65歳以上）：2050年に約442万人でピーク（2010年実績約268万人の約1.6倍）→ 2100年約327万人。
- 老年人口比率：2100年に約46%（うち75歳以上が約33%）。
- 生産年齢人口（15〜64歳）：2050年約631万人（2010年比3割減）→ 2100年約331万人（2010年比6割以上減）、比率約47%（46.5%）。
- 年少人口：2010年比で2050年に約2/3、2100年に約1/3（約54万人）へ減少。
- 区部の方が市部より急激に減少。

**出生率上昇シナリオ**では2100年総人口約1,224万人（高齢化率30.8%）等の並列推計も提示。**外国人比率のシナリオ**（研究会推計）：外国人比率は2010年2.5%から2100年に約40%に達し、特に区部では約47%となる。この「出生率上昇＋外国人流入」シナリオでは総人口はベース推計比で約470万人増、生産年齢人口は2100年約600万人（ベース推計の約1.8倍）とされる。

#### 2-2. 東京都世帯数の予測（一次情報：東京都総務局、2024年3月公表、2045年まで）
- 一般世帯数：2035年の768.3万世帯でピーク → 2045年760.6万世帯。
- 1世帯当たり人員：2020年1.92人 → 2045年1.79人（区部は1.74人、多摩・島しょは1.93人）。
- 高齢世帯（世帯主65歳以上）：2045年263.5万世帯（一般世帯の34.7%）。
- 高齢単独世帯：2045年122.3万世帯（高齢世帯の46.4%）、うち75歳以上が65.6万世帯で半数超。
- （2050東京戦略附属資料では、平均世帯人員は2020年1.95人→2065年1.81人と、2065年までの推計も提示。）

#### 2-3. IPSS「日本の将来推計人口（令和5年推計）」（一次情報：国立社会保障・人口問題研究所、2023年）
出生3仮定×死亡3仮定の9本の基本推計（2021〜2070年）と長期参考推計（2071〜2120年）。**出生中位・死亡中位推計：**
- 総人口：2020年1億2,615万人 → 2050年約1億469万人（17%減）→ 2070年8,700万人（31%減）。
- 高齢化率：2020年28.6% → 2070年38.7%。
- 生産年齢人口比率：2070年52.1%。合計特殊出生率の仮定：1.36（中位）。
- 0〜14歳人口：2053年に1,000万人割れ、2070年797万人。
- 外国人：入国超過数の長期的仮定を前回の年約6.9万人から年約16.4万人へ引き上げ。外国人人口は2070年に939万人（2020年275万人の約2.4倍）、総人口に占める外国人比率は2070年に10.8%。

#### 2-4. 世帯の全国将来推計（一次情報：IPSS「日本の世帯数の将来推計（全国推計）」令和6年推計、2024年、2050年まで）
- 一般世帯総数：2020年5,570万世帯 → 2030年5,773万世帯でピーク → 2050年5,261万世帯。
- 平均世帯人員：2020年2.21人 → 2033年に初めて2人割れ。
- 65歳以上世帯主の世帯割合：2020年50.9% → 2050年62.0%。

#### 2-5. 国連「世界人口推計（World Population Prospects 2024）」（一次情報：国連経済社会局、2024年7月11日発表）
- 日本の人口：2100年に約7,685万人（中位推計。人口ピークは2009年頃約1.28億人）。
- 世界人口：2024年82億人 → 2080年代半ば約103億人でピーク → 2100年約102億人。
- 日本は2024年時点ですでに人口ピークを迎えた63の国・地域の一つ。

### 3. 都市機能

#### 3-1. 「2050東京戦略」（一次情報：東京都政策企画局、2025年3月策定）
「未来の東京」戦略を発展させた都の総合計画。「セーフシティ」「ダイバーシティ」「スマートシティ」の3つのシティを進化させ、「成長」と「成熟」が両立した「世界で一番の都市・東京」を目指す。2050年代のビジョンと2035年に向けた戦略を設定。
- **主要政策の例**：太陽光パネル設置義務化、次世代型ソーラーセル（Airソーラー）・浮体式洋上風力等の再エネ、水素エネルギー、熱中症対策、「倒れない・燃えないまちづくり」（首都防衛）、AI活用行政（「東京都AI戦略」2025年策定）、鉄道ネットワーク充実（東京8号線延伸、多摩都市モノレール延伸）、デマンド交通・舟運等。
- **「22世紀の予言」**：これまでの延長線にとらわれない発想で未来を展望する試みとして、生成AIを活用して100年後（22世紀）の未来予測を行い、新聞形式でとりまとめた。「宇宙が生活圏となり誰もが宇宙旅行を楽しむ」「五感をデータで共有できる」等のイメージを提示（AIによる生成であり、動画内の人物等も実在しないと明記）。

#### 3-2. 首都直下地震・南海トラフ地震（一次情報：地震調査研究推進本部・内閣府）
- **首都直下地震**：M7クラスの発生確率は今後30年以内に70%程度（地震調査研究推進本部）。
- **南海トラフ地震**：M8〜9クラス、30年以内の発生確率は「20〜50%」または「60〜90%程度以上」（2025年1月1日基準、南海トラフの地震活動の長期評価第二版一部改訂、地震調査研究推進本部）。
- **首都直下地震・新被害想定（政府・中央防災会議作業部会、2025年12月19日公表、12年ぶり改定、主査は増田寛也元総務相）**：東京都心南部を震源とするM7クラスで、最悪の場合（冬・夕方18時頃・風速8m/s）約1万8千人が死亡（前回想定2万3千人から減少）、経済的被害・影響額約83兆円。建物全壊・焼失約40万棟（揺れ全壊約11万棟、火災焼失約27万棟）。災害関連死は最大4万1千人と想定。10年間の防災対策進展等で前回より被害減。
- **南海トラフ巨大地震・新被害想定（内閣府、2025年3月公表）**：最大ケースで建物全壊・焼失235万棟（前回比2%減）。うち揺れ全壊127万9千棟、津波全壊18万8千棟（前回比22%増）等。

#### 3-3. インフラ老朽化（一次情報：国土交通省、2023年3月時点）
「建設後50年以上経過する社会資本の割合」：
- 道路橋：2023年約37% → 2030年約54% → 2040年約75%。
- トンネル：2023年約25% → 2040年約52%。
- 下水道管：2030年約16% → 2040年約34%。港湾施設：2040年約68%。
- 維持管理・更新費：予防保全で約5.9〜6.5兆円に対し、事後保全では2048年度に最大12.3兆円（国交省試算）。

#### 3-4. 国土の長期展望（一次情報：総務省・国土交通省）
総務省「自治体戦略2040構想研究会」「国土のグランドデザイン2050」等は、2050年に非居住地化する地域の出現、水需要減少、管路更新率0.76%（H26）では全管路更新に130年かかること等を指摘。

### 4. 経済

#### 4-1. IMF「世界経済見通し（WEO）」（一次情報：IMF、2025年10月14日発表）
- 日本の名目GDP（ドル建て）：2023年にドイツに抜かれ4位 → 2026年にインドに抜かれ5位（2026年日本4兆4,636億ドル、インド4兆5,056億ドル。円安による目減りが背景）。日本は2030年も5位を維持する見通し。

#### 4-2. 東京都の都内総生産（一次情報：東京都「都民経済計算 令和5年度年報」2026年3月公表）

#### 4-3. PwC「World in 2050」（民間予測：PwC、2017年版）

#### 4-4. ゴールドマン・サックス「The Path to 2075」（民間予測：Goldman Sachs、2022年）
- 2050年の上位5経済：中国、米国、インド、インドネシア、ドイツ（日本は5位圏外へ）。
- 2075年：日本は12位に後退（ドイツは9位、英国10位）。世界最大5経済は中国・インド・米国・インドネシア・ナイジェリア。
- 日本の人口は2075年に約8,600万人へ減少するとの前提。

#### 4-5. 2100年を直接対象とした経済予測
主要な公的機関・国際機関（IMF・OECD・世界銀行）による2100年を直接対象とした名目GDP予測は確認されない。民間長期予測も2050年（PwC）・2075年（Goldman Sachs）が最長期であり、2100年の東京・日本のGDPを直接示す信頼できる予測は乏しい。

## Recommendations（情報活用上の留意点）
本レポートは情報収集・整理に徹する性質上、政策提言ではなく、収集した情報を利用する際の段階的な留意点を示す。
1. **まず一次情報を確認する**：本文中の各数値は、環境省・気象庁・IPSS・内閣府・国交省・東京都・IMF・国連の公式PDF等が原典である。引用の際は最新版の更新状況（特に人口推計は約5年ごと、被害想定・GDP・マンションストックは年次更新）を必ず確認する。
2. **シナリオを併記する**：気候は2℃／4℃（RCP2.6／RCP8.5、SSP1-2.6／SSP5-8.5）、人口は出生高位／中位／低位・外国人流入仮定別で結果が大きく異なるため、単一値ではなく範囲・シナリオ名で扱う。
3. **公的推計と民間予測・啓発コンテンツを区別する**：環境省「未来の天気予報」は啓発コンテンツ、PwC・Goldman Sachs・野村総研・日本総研は民間予測、東京都「22世紀の予言」は生成AIによる試作である旨を明示して利用する。
4. **対象年次のズレを明示する**：2100年の直接推計がある項目（都の人口、環境省天気予報、国連人口）と、2050・2065・2070年等で代替する項目（世帯、経済、インフラ、マンション）を区別する。
5. **閾値の目安**：気候では「1.5℃／2℃/4℃到達年代」、人口では「1,000万人割れ（2070年）」「高齢化率46%（2100年）」、防災では「30年以内70%（首都直下）」が主要な参照点となる。

## Caveats（留意事項）
- 人口・世帯推計は趨勢延長型であり、出生率・移民政策・平均寿命の変化で実績が大きく乖離しうる。実際、野村総合研究所の空き家率予測は世帯数の想定以上の増加により下方修正されており、趨勢延長型推計の不確実性を示している。
- 環境省「2100年 未来の天気予報」（2019年、IPCC AR5のRCPベース）の数値は啓発目的の想定値であり、最新の「日本の気候変動2025」（IPCC AR6準拠）の予測値とは前提年次・シナリオが異なる。
- 「東京の自治のあり方研究会」の外国人比率約40%シナリオは、特定の移民流入仮定に基づく条件付き推計であり、都の公式な人口目標ではない。
- 東京都の高潮浸水想定はRCP8.5等の気候変動シナリオを直接前提とするものではなく、水防法に基づく「想定最大規模」を前提とする。
- 2100年を直接対象とした経済（GDP）の公的・国際機関予測は確認されず、民間予測も最長2075年（Goldman Sachs）である。
- 首都直下地震・南海トラフ地震の被害想定は最悪ケース（時間帯・季節・風速の条件）を含み、確率的発生予測とは性質が異なる。
- 一部の数値（マンションストックの旧世代データ「2042年末445万戸」等）は民間サイト経由で流通しているが、国交省公式最新版（2024年末実績ベース）とは異なるため、本レポートでは公式最新版を採用した。
- 都内総生産の「約110兆円」は令和2年度（コロナ禍、109.6兆円）に該当し、直近の令和5年度は約125兆円に拡大している点に注意。
