## 1. 「まだ誰も取り組んでいないこと」（転記用）

- 見守り・MaaS・介護ロボット・PHR・シニア就労マッチングの**単機能サービスはすべてレッドオーシャン**。MaaSは国の実証が累計約119事業あり、その多くが継続していない（「実証疲れ」）
- 空白は3つ
  1. **既存サービスを地区単位で束ねる統合レイヤー**（Ageing District Stack）
  2. **実証終了後もサービス・データが引き継がれる出口設計**（撤退・引継ぎの標準仕様）
  3. **高齢者の記憶・技能の公共資産化**（海外はスタートアップが集積、日本の公共文脈はほぼ空白）
- 都知事杯の過去5回（2021〜2025）で、**高齢者・介護を主対象にした受賞作はゼロ**。土俵そのものが空いている

## 2. 「今回取り組むこと」（転記用）— 具体的課題 9個

作るものは1つ: **SILVERPUNK PROOF MAP**（2100年ストレステスト付き・パイロット地区選定の道具）。
9個の課題はその部品であり、**どれか1つでも動けば単独で成立する**ように切ってある。
件数はすべて東京都オープンデータカタログ全9,678件（2026-07-04取得）への実測値。

| # | 課題 | 使うOD（実測） | 対応ギャップ |
|---|---|---|---|
| **T1** | **2100年の視界切れを埋める** — 東京都の2100年人口に公式値はない（公的推計は2050/2065年で切れる）。コーホート要因法で2100年まで都民が自分で動かせるようにする。**計算コードは実装済み**（[cohort.py](../concept-research/20260822-tokyo-zero-inflow-cohort.py)） | 人口・住民基本台帳 **936件** | 前提そのもの |
| **T2** | **「東京を支えているのは誰か」の可視化** — 国内転入ゼロの影響は国外転入ゼロの**約5.4倍**（実測済み）。国内/国外を独立トグルにして、この非対称性を画面上の発見にする | 住民基本台帳人口移動報告 | 制度・労働 |
| **T3** | **「2100年の東京」に一番早く着く街を探す** — 高齢化率46%（2100年の東京水準）に区市町村・町丁がいつ到達するかを計算。未来はもう都内のどこかで始まっている | 年齢別・町丁別人口 **233件**／将来人口・推計 **108件** | 全ギャップの実証地 |
| **T4** | **パイロット候補地スコアリング** — 高齢者密度×職住医福の近接×交通で区市町村を採点し、上位3地区を同じ指標で比較 | 高齢者129・介護121・医療72・交通215・公園/トイレ220件 | 制度・資本（D3意思決定） |
| **T5** | **候補業務の実在確認** — 選定地区の高齢就労の受け皿（実演型業態・シルバー人材）を一覧化し「最初の1業務」を仮置き | 就労・シルバー人材 **49件**／敬老・老人クラブ 10件 | 労働・文化 |
| **T6** | **記憶アーカイブ優先度リスト** — 唯一の時間切れ型ギャップ（G7）。文化財・伝統工芸・銭湯の残存分布から「先に収録すべき地区と資源」を出す | 文化財・伝統工芸 **48件**／銭湯 8件 | 記憶（P0・不可逆） |
| **T7** | **暑熱×要支援のリスクレイヤ** — 2100年は猛暑日30日。避難・防災ODと高齢者分布を重ね、選定地区の気候適応の弱点を見る | 避難所・防災 **151件** | モビリティ・防災 |
| **T8** | **欠損マップ＝「選定に必要なデータの半分が公開されていない」** — 空き店舗**0件**・商店街3件・銭湯8件・バリアフリー13件・認知症2件・クーリングシェルター3件。欠損を推定で埋めず、理由付きで明示して行政への提言に変える | カタログ全9,678件そのもの | データ統合（欠けの証明） |
| **T9** | **パイロットカード出力** — 選定1地区について、未解決ギャップのチェックリスト＋KPIベースライン＋次の30日のアクション＋中止条件を1ページで出力。「作って終わり」にしない出口設計 | T1〜T8の統合 | 資本・出口設計（空白領域②） |

### 採用しなかったもの（理由つき）

| 不採用 | 理由 |
|---|---|
| 経路計算つき到達性マップ | 2日に対して実装が重い。断念率KPIは実測が必要で当日は測れない |
| HaaSマッチングUI | 個人の健康・職務適合データは**ODに存在しない**。審査基準①（データ活用の有効性）が立たずモックで終わる |
| 見守り・MaaS・介護ロボ単体 | レッドオーシャン（§1のとおり） |

### 優先順位

核は **T1+T2**（実装資産があり当日の博打ゼロ）→ **T3** → **T4** → **T8** → **T9**。
T5/T6/T7 は時間次第で足すレイヤ。

**T3が企画の蝶番** — 「2100年は予測ではなく、もう都内のどこかで始まっている」で、
前提（人口動態）→ あるべき姿（SILVERPUNK 2100）→ 今回取り組むこと が一本に繋がる。
