# docs/hypothesis-validation

調査レポート（[`../research/`](../research)）から立てた仮説を、公的統計の突合と再現可能なモデルで検証した結果の置き場。

各レポートは「仮説 → 検証手法 → データ → 判定 → 限界」の構成をとり、**実データと独自仮定を明示的に区別する**方針で記述する。

| :-- | :-- | :-- |
| [東京都の人口は移動にどれだけ依存しているか](20260822-tokyo-population-migration-dependency.md) | 東京都の人口増加が国内転入・海外からの流入にどの程度依存しているか | 5仮説すべて支持。2100年時点で人口の40.9%が移動由来 |

## モデルの再現

```bash
# 全シナリオの表を標準出力へ
python3 docs/hypothesis-validation/scripts/tokyo_cohort_model.py

# 全系列をCSVへ書き出し
python3 docs/hypothesis-validation/scripts/tokyo_cohort_model.py \
  --csv docs/hypothesis-validation/data/tokyo-cohort-projection.csv
```

外部ライブラリへの依存なし（Python 3 標準ライブラリのみ）。

## 検証済みの主要な数値

東京都の人口（万人）。詳細と前提は各レポートを参照。

| 年 | 移動あり（公式推計を再現） | 移動ゼロ | 移動への依存率 |
| --: | --: | --: | --: |
| 2026 | 1,449 | 1,376 | 5.1% |
| 2030 | 1,467 | 1,351 | 7.9% |
| 2050 | 1,380 | 1,108 | 19.7% |
| 2075 | 1,072 | 726 | 32.2% |
| 2100 | 669 | 395 | 40.9% |

モデルは東京都公式推計（2020〜2065年）を**最大乖離3.8%**で再現している。

## 記述方針

1. **実データと独自仮定を必ず区別する。** 公的統計から取った値と、モデルのために置いた近似値を表や注記で明示する。
2. **モデルは検証してから使う。** 反実仮想を語る前に、既知の公式推計を再現できることを確認する。
3. **限界を省略しない。** 仮定の脆さ、既知の偏り、モデル化していない要素を各レポートに明記する。
4. **再現可能にする。** 数値を出したコードとデータをリポジトリに含める。
