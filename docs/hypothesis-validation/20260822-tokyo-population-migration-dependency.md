# 東京都の人口は移動にどれだけ依存しているか — 仮説検証レポート

- 作成日: 2026-08-22
- 対象: 東京都（日本全国・世界を比較参照）
- 検証手法: 公的統計の突合 ＋ 5歳階級コーホート要因法モデルによる反実仮想シミュレーション
- 再現用コード: [`scripts/tokyo_cohort_model.py`](scripts/tokyo_cohort_model.py)
- 出力データ: [`data/tokyo-cohort-projection.csv`](data/tokyo-cohort-projection.csv)

---

## 1. 要旨

東京都は2012年に自然減（死亡数が出生数を上回る状態）へ転じており、**現在の人口増加は国内転入超過と外国人住民の増加という「移動」のみによって成立している**。本レポートは、この構造がどの程度の規模なのかを、年齢構造を明示的に扱うコーホート要因法モデルで定量化した。

主要な結果は次の3点である。

1. **モデルは東京都公式推計を最大乖離3.8%で再現できた。** 2025年実績の純移動（年12.6万人）が5年ごとに0.76倍へ逓減すると仮定した場合、2020〜2065年の公式推計7時点を再現する。つまり**東京都の公式推計は「転入超過が今後大きく逓減する」ことを暗黙の前提としている**。

2. **移動を完全にゼロと仮定すると、東京都は加速度的に縮小する。** 2100年時点で395万人（TFR 0.90）となり、移動を織り込んだ場合の669万人に対して**約274万人（40.9%）少ない**。減少率は2020年代の年▲0.3%から2090年代には年▲2.5%へと8倍に加速する。

3. **東京の人口を支えているのは、出生ではなく20代の転入である。** 移動ゼロシナリオでは15〜64歳人口が2100年に180万人（2020年比▲80.6%）まで縮小し、高齢化率は48.4%に達する。

この結果は「東京の人口規模は、地方および海外からの若年人口の供給を原資として維持されている」という構造仮説を支持する。

## 4. モデルの構造と妥当性検証

### 4.1 モデルの構造

5歳階級（0〜4歳 … 95〜99歳、100歳以上の21階級）のコーホート要因法。1ステップ = 5年で以下を実行する。

```
1. 各階級の人口 × 生残率        → 1つ上の階級へ送る
2. 15〜49歳女性 × 出生パターン × TFR → 出生数
3. 出生数 × 乳幼児生残率        → 新しい0〜4歳階級
4. 年齢別純移動数を加算          ← 移動ゼロシナリオではこの項を0にする
```

推計の基本恒等式は `翌年人口 = 当年人口 + 出生 − 死亡 + 純移動` であり、本モデルはこの第4項を操作することで反実仮想を作る。

### 4.2 なぜキャリブレーションが必要か

移動ゼロの結果を信頼するには、まず**移動を入れた状態でモデルが公式推計を再現できること**を確認しなければならない。再現できないモデルの反実仮想は、移動の効果ではなくモデルの誤差を測っていることになる。

### 4.3 キャリブレーション結果

2025年実績の純移動（年125,723人）を投入し、公式推計7時点に対してRMSEを最小化する `(移動減衰係数, TFR)` をグリッドサーチした。

**最適パラメータ: 移動減衰係数 0.76（5年ごと）、TFR 0.90**

| 年 | モデル | 東京都公式推計 | 乖離 | 乖離率 |
| --: | --: | --: | --: | --: |
| 2020 | 1,404.0万人 | 1,405万人 | ▲1.0万人 | ▲0.1% |
| 2025 | 1,444.8万人 | 1,421万人 | +23.8万人 | +1.7% |
| 2030 | 1,466.9万人 | 1,426万人 | +40.9万人 | +2.9% |
| 2040 | 1,455.9万人 | 1,403万人 | +52.9万人 | +3.8% |
| 2050 | 1,380.0万人 | 1,357万人 | +23.0万人 | +1.7% |
| 2060 | 1,268.4万人 | 1,278万人 | ▲9.6万人 | ▲0.7% |
| 2065 | 1,206.3万人 | 1,231万人 | ▲24.7万人 | ▲2.0% |

**最大乖離3.8%**で公式推計を再現できた。45年間の投影としては十分な一致であり、モデルの骨格（年齢構造・生残・出生・移動の各項）が妥当に機能していることを示す。

**この検証自体が発見でもある。** 移動を減衰させず現水準で永久に継続させると、2065年に1,660万人となり公式推計から**+34.9%乖離**する。つまり東京都公式推計は、「地方の若年人口が枯渇するため転入超過は逓減する」という前提を強く織り込んでいる。5年ごとに0.76倍という減衰は、**2065年時点で純移動が現在の約15%まで縮小する**ことを意味する。

### 4.4 モデルの既知の偏り

- 2026年時点でモデルは1,449.2万人、実績は1,430.2万人で**+19.0万人（+1.3%）の上振れ**。近年の投影がやや過大である。
- モデルのピークは2035年1,470.7万人で、公式推計のピーク（2030年1,426万人）より5年遅く45万人高い。
- したがって移動ありシナリオの数値は**やや楽観側**であり、移動ゼロとの差（＝移動依存度）はわずかに過大評価されている可能性がある。

## 5. 仮説ごとの検証

### 5.1 H1: 東京都は既に自然減であり、人口増加は移動のみで成立している → 支持

2025年中の東京都の人口変動の内訳は次のとおり。

| 要因 | 年間変動 | 性質 |
| :-- | --: | :-- |
| 日本人の自然増減（出生 − 死亡） | **▲54,153人** | 減少要因 |
| 日本人の国内純移動（地方からの転入超過） | +63,245人 | 増加要因 |
| 外国人住民の純増 | +62,478人 | 増加要因 |
| **合計** | **+75,018人** | — |

東京都は2012年に自然減へ転換している。上表のとおり、**自然増減はマイナスであり、人口増加の全額が移動由来**である。純移動（+125,723人）は自然減（▲54,153人）の2.3倍の規模を持ち、差し引きで人口を押し上げている。

仮説は成立する。なお「国内転入」と「海外からの流入」の寄与はほぼ同等（6.3万人 対 6.2万人）であり、**外国人住民の増加は既に国内転入と並ぶ柱になっている**点は、一極集中の議論で見落とされやすい。

### 5.2 H2: 移動がゼロなら東京都の人口減少は加速度的に進む → 支持

移動ゼロ・TFR 0.90シナリオにおける年平均減少率の推移。

| 期間 | 年平均減少率 |
| :-- | --: |
| 2020〜2025 | ▲0.32% |
| 2030〜2035 | ▲0.65% |
| 2040〜2045 | ▲1.12% |
| 2050〜2055 | ▲1.42% |
| 2060〜2065 | ▲1.66% |
| 2070〜2075 | ▲1.96% |
| 2080〜2085 | ▲2.34% |
| 2090〜2095 | **▲2.55%** |

減少率は70年間で**約8倍に加速**する。これは単なる自然減の継続ではなく、**人口モメンタムの喪失**による。転入がゼロになると出産可能年齢の女性人口が世代を追うごとに補充されなくなり、TFRが一定でも出生数が世代ごとに縮小する。一方で高齢者は死亡するまで残るため、分母の縮小と分子の縮小が同時に進み、減少が複利で効いていく。

年齢構造への影響は総人口以上に大きい。

| 指標 | 2020年 | 2100年（移動ゼロ・TFR 0.90） | 変化 |
| :-- | --: | --: | --: |
| 総人口 | 1,404万人 | 395万人 | ▲71.9% |
| 0〜14歳 | 157万人 | 23.7万人 | ▲84.9% |
| 15〜64歳 | 928万人 | 180万人 | **▲80.6%** |
| 65歳以上 | 319万人 | 191万人 | ▲40.1% |
| 高齢化率 | 22.7% | **48.4%** | +25.7pt |

### 5.3 H3: 東京都公式推計は転入超過の大幅な逓減を前提にしている → 支持

§4.3で示したとおり、移動を現水準で一定に保つと公式推計から2065年に+34.9%乖離し、5年ごと0.76倍の減衰を入れると最大乖離3.8%に収まる。

この前提は調査レポート群の記述とも整合する。東京都の推計は「直近の過度な転入超過率が永久に継続するとは仮定せず、過密化や地方側の人口枯渇を踏まえて将来的に社会移動量が漸減・収束していく減衰シナリオ」を組み込んでいるとされる。

**含意**: 「東京都の人口は2065年に1,231万人まで減る」という公式推計は、既に**転入超過がほぼ消滅した世界**を描いている。したがって本レポートの移動ゼロシナリオは、公式推計に対して質的に異なる未来ではなく、**同じ方向の変化を時間的に前倒ししたもの**と理解するのが正確である。

### 5.4 H4: 地方の人口減少は社会減より自然減が主因である → 支持（先行研究に依拠）

調査レポート群によれば、**非大都市圏における人口減少の96.7%が自然減**によって占められている。地方の人口減少は「若者が東京へ流出するから」ではなく、既に出産可能年齢人口が枯渇していることが主因である。

**本モデルでは地方側を明示的にモデル化していないため、この仮説は先行研究の引用にとどまる。** ただし、H3で確認した「転入超過の逓減」は、地方側の若年人口が減り東京へ供給できる母数そのものが細ることの帰結であり、両者は同じ構造の表裏である。

政策的には重要な含意を持つ。**東京一極集中の是正だけでは地方の人口減少は止まらない**。転入超過をゼロにしても、地方の人口減少の96.7%を占める自然減は残るためである。

### 5.5 H5: 2100年の東京都人口には公式推計が存在せず、推計幅が極めて大きい → 支持

東京都の公式推計は**2065年で終端**しており、2100年の公式値は存在しない。既存の試算と本モデルの結果を並べると、幅は約760万人に及ぶ。

| 出所 | 2100年 東京都人口 | 前提 |
| :-- | --: | :-- |
| 旧・東京都長期推計（2010年基準） | 713万人 | 2020年ピーク1,335万人を前提。実績1,405万人がこれを上回り前提が崩れている |
| 感度分析ケースA（全国シェア固定） | 844万人 | 2065年公式値に社人研の全国減少率を適用 |
| 感度分析ケースB（緩やかな集中継続） | 942万人 | 社人研2100年全国人口 × 東京シェア15% |
| 感度分析ケースC（国連寄りの全国人口） | 1,153万人 | 国連2100年全国人口 × 東京シェア15% |
| **本モデル・移動あり（キャリブレーション済）** | **669万人** | TFR 0.90・移動減衰0.76/5年 |
| **本モデル・移動ゼロ TFR 1.36** | **660万人** | 移動なし・全国中位水準までTFR回復 |
| **本モデル・移動ゼロ TFR 1.00** | **446万人** | 移動なし |
| **本モデル・移動ゼロ TFR 0.90** | **395万人** | 移動なし |

本モデルの移動ありケース（669万人）が旧長期推計（713万人）に比較的近い値へ収束した点は興味深いが、両者は基準年も手法も異なるため**偶然の一致として扱うべき**である。

なお、感度分析ケースA〜Cが本モデルより高い値を示すのは、これらが「東京都の全国シェアが将来も維持される」ことを前提とするのに対し、本モデルは年齢構造を明示的に扱い、出産可能人口の縮小を通じた出生数の逓減を内生的に織り込むためである。**シェア固定型の外挿は、東京の低出生率がもたらす長期的な縮小圧力を過小評価する傾向がある。**

† 公表値の間を直線補間した参考値。‡ 全国値から東京都値を差し引いた独自計算であり、地方単独の公式推計ではない。

## 7. 本レポートの限界

1. **5歳階級の内訳・生残率・出生パターン・移動配分はすべて独自仮定**であり、東京都固有の統計に基づくものではない。絶対値の精度には限界があり、**方向性とオーダーの把握に用いるべきである**。
2. **近年の投影が上振れしている**（2026年で+1.3%）。移動ありシナリオの数値はやや楽観側であり、移動依存度はわずかに過大評価されている可能性がある。
3. **TFR・生残率・移動配分を全期間で一定と仮定している。** 実際には医療技術の進歩、住宅政策、外国人受入れ制度、災害などにより変動する。
4. **「移動ゼロ」は現実には起こり得ない極端な思考実験である。** 東京都は国内最大の雇用・教育集積地であり、転入が完全に止まる状況は想定されない。この試算は「東京の人口規模がどれだけ移動に依存しているか」を可視化するための反実仮想である。
5. **地方側をモデル化していない。** H4は先行研究の引用にとどまる。東京と地方を同時に扱う多地域モデルは今後の課題である。
6. **社人研や東京都の公式推計を代替するものではない。** 公式推計はより精緻な年齢別データ、コーホート出生モデル、Lee–Carterモデル等に基づいており、本モデルはその構造を簡略化して反実仮想を作るための道具である。
