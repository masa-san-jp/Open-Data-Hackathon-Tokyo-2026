## 2. 必要要件(構想の成立前提)

- **制度**: 医療・労働・ビザを一括で扱う特区指定。2026年4月から高年齢労働者の労災防止措置が事業者義務化されており、安全投資は「任意」ではなく法的前提
- **技術**: 市街地全域レベルの無人モビリティ認可、ウェアラブル常時監視の精度・装着負担・電源、同時翻訳の低遅延化
- **資本**: 都市改修と医療集積の初期投資を賄う官民スキーム(特区+PFI等)
- **社会的合意**: 常時バイタル監視への本人同意設計、「働く高齢者」を搾取でなく誇りとして描くブランド設計

## 3. 課題

- **労災リスク(最重要)**: 休業4日以上の労災死傷者のうち60歳以上が約3割で過去最多を更新中。発生率(千人率)は60歳以上4.0に対し全体平均2.4、事故型は転倒が突出(60歳以上の災害の38%)。パワーアシスト・転倒対策は「あれば良い」ではなく成立の必須条件
- **稼働の不安定性**: 体調由来の欠勤・短時間化が常態となるため、HaaSには大きな需給バッファ(多能工化・予備人員・ロボット代替)の設計が必要
- **医療資源の配分**: 医療ツーリズム拡大は国内医療の逼迫・二重価格批判と表裏。特区内で国内医療と分離する制度的工夫が必要
- **気候負荷**: 2100年の東京の夏は高齢者の屋外労働に不適な水準が想定される。前版で削除した気候制御インフラは再検討の余地あり
- **プライバシー**: 常時ヘルスモニタリングは監視社会批判と直結。データ主権・同意の設計が必要

## 4. 反証(コンセプトが成立しない可能性)

| 反証仮説 | 内容 | 対抗論拠 |
|---|---|---|
| 自動化優位 | 2100年にはロボット接客が品質・コストで人間を上回り「人的接客」市場が消滅する | 高級ホスピタリティでは人的接触がラグジュアリー化する潮流。DAWNは「人が介在すること自体」への支払意思を既に実証 |
| 労働供給の枯渇 | 2100年の日本は総人口約6,300万人・高齢化率40%の推計。高齢者の絶対数も減り労働供給が想定を下回る | 高齢化率40%は「高齢者が最大の労働資源」であることの裏返し。全国から居住込みで集める都市設計(住環境要件)が回答になる |
| ノスタルジー需要の消滅 | 20〜21世紀を実体験した世代が消え、需要の核が失われる | 明治村等、非体験世代への「歴史観光」として成立する前例あり。ただし需要規模は縮小前提で設計すべき |
| 医療ツーリズム競争激化 | タイ・韓国・海南島等の先行国との価格競争に巻き込まれる | 勝ち筋は価格でなく「エイジング医療×長期滞在×体験都市」の複合。単品の医療輸出では勝てない前提で設計する |
| 倫理的批判 | 「高齢者を働かせる都市」というレピュテーションリスク | 完全選択制・尊厳ある職務設計・就労が健康寿命延伸に寄与するエビデンス提示が必須。成立すれば医療価値と一体化できる |

## 5. 総合所見

- 構想の各要素には**個別の実証済み先行事例が存在**する。技術的な未踏領域は少なく、本質的な難所は「統合」と「特区制度設計」
- 定量面で最重要のリスクは**高齢者労災**(発生率が全体平均の約2倍・転倒偏重)。安全投資は投資優先度の最上位
- 反証のうち最も重いのは**自動化優位仮説**と**ノスタルジー需要の持続性**の2点。次の検証ステップは需要側の定量調査(誰が・何に・いくら払うか)
